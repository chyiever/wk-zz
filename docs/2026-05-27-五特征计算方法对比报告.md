## 2. 两个 notebook 的数据处理流程对比

### 2.1 数据流程（完全一致）

两个 notebook 均采用相同的处理流程：

```
原始 TDMS 文件
    ↓ 读取长通道信号
整条信号去均值 + (1k, 95k) Hz 4阶零相位 Butterworth 带通滤波
    ↓ 预处理一次，复用
滑窗切割（20 ms 窗口，50% 重叠）
    ↓ 每窗口独立计算
对每个窗口构建 FeatureRecord → build_context → 提取5个特征
    ↓
输出到 CSV
```

关键参数（两者完全一致）：

| 参数 | 值 |
|---|---|
| `WINDOW_DURATION_S` | 0.02 s（20 ms） |
| `WINDOW_OVERLAP` | 0.50（50%） |
| `PREPROC_BAND` | (1000.0, 95000.0) Hz |
| 预处理滤波阶数 | 4 阶 Butterworth |
| 频带定义 | `b_1k_10k`: (1k, 10k)，`b_1k_100k`: (1k, 100k) |

> **澄清**：两个 notebook 均**不是**对整段信号计算特征，而是对滑窗后的每个 20 ms 窗口分别计算特征。

### 2.2 `build_params_for_band` 实现（完全一致）

两个 notebook 中均定义了相同的 `build_params_for_band` 函数，用于为每个频带生成 `FeatureParams`：

```python
def build_params_for_band(band, sample_rate):
    low, high = band
    nyq = sample_rate / 2.0
    low, high = _safe_band(low, high, nyq)
    span = max(high - low, 10.0)

    ridge_main = _safe_band(low, low + 0.65 * span, nyq)
    ridge_h2   = _safe_band(max(low * 2.0, low + 0.20 * span),
                             min(high * 2.0, nyq * 0.995), nyq)

    return replace(DEFAULT_FEATURE_PARAMS,
                   highpass_hz=1_000.0,
                   main_band_hz=(low, high),
                   ridge_main_search_hz=ridge_main,
                   ridge_h2_search_hz=ridge_h2,
                   n_jobs=1)
```

以 500 kHz 采样率为例，各频带的参数值：

| 频带 | `main_band_hz` | `ridge_main_search_hz` | `ridge_h2_search_hz` |
|---|---|---|---|
| `b_1k_10k` | (1000, 10000) | (1000, 6850) | (2800, 20000) |
| `b_1k_100k` | (1000, 100000) | (1000, 65350) | (20800, 200000) |

## 3. 特征计算代码对比

### 方法 A：build-3 notebook 自定义函数

build-3 在 Helpers 单元格中内联定义了五个特征的专用计算函数，再在 `compute_5_features_for_window` 中调用：

```python
def compute_5_features_for_window(window_signal, sample_rate, params_map):
    rec = FeatureRecord(signal=window_signal, sample_rate=sample_rate, ...)

    ctx_1k10k  = build_context(rec, params_map['b_1k_10k'])
    ctx_1k100k = build_context(rec, params_map['b_1k_100k'])

    return {
        'b_1k_10k__SC_mean':      _spectral_centroid_mean(ctx_1k10k.stft_freqs,
                                                           ctx_1k10k.stft_power,
                                                           ctx_1k10k.params.eps),
        'b_1k_10k__C_f':          _c_f_from_context(ctx_1k10k),
        'b_1k_100k__epsilon_2x':  _epsilon_2x_from_context(ctx_1k100k),
        'b_1k_100k__SC_res_mean': _sc_res_mean_from_context(ctx_1k100k),
        'b_1k_100k__I_burst':     _i_burst_from_context(ctx_1k100k),
    }
```

五个自定义函数源码：

```python
# SC_mean：STFT 功率谱的逐帧谱心均值
def _spectral_centroid_mean(freqs, power, eps):
    if power.size == 0:
        return 0.0
    numerator   = np.sum(freqs[:, None] * power, axis=0)
    denominator = np.sum(power, axis=0) + eps
    sc = numerator / denominator
    return float(np.mean(sc)) if sc.size else 0.0

# C_f：脊线频率轨迹的归一化曲率均值
def _c_f_from_context(context):
    eps = context.params.eps
    if len(context.ridge_f1) <= 2:
        return 0.0
    curvature = np.gradient(
        np.gradient(context.ridge_f1, context.stft_times + eps),
        context.stft_times + eps,
    )
    return float(np.mean(np.abs(curvature) /
                         (np.mean(np.abs(context.ridge_f1)) + eps)))

# epsilon_2x：二次谐波脊线相对频率偏差中位数
def _epsilon_2x_from_context(context):
    eps    = context.params.eps
    active = context.ridge_f1 > 0.0
    if not np.any(active):
        return 0.0
    diff_h2 = np.abs(context.ridge_f2 - 2.0 * context.ridge_f1)
    return float(np.median(diff_h2[active] / (context.ridge_f1[active] + eps)))

# SC_res_mean：残差 STFT 功率谱的逐帧谱心均值
def _sc_res_mean_from_context(context):
    eps = context.params.eps
    return float(_spectral_centroid_mean(
        context.stft_freqs, context.residual_power, eps))

# I_burst：小波包节点能量分布的突发指数
def _i_burst_from_context(context):
    eps        = context.params.eps
    total_wp   = float(sum(context.wavelet_node_energies.values())) + eps
    sorted_nodes = sorted(context.wavelet_node_energies.items())
    wp_prob    = np.asarray([e / total_wp for _, e in sorted_nodes], dtype=float)
    return float(np.max(wp_prob) / (np.median(wp_prob) + eps))
```

## 4. 逐特征差异分析

| 特征 | 差异类型 | 说明 |
|---|---|---|
| `SC_mean` | 空数组保护 | 方法 A 在入口加了 `if power.size == 0: return 0.0`；方法 B 无此保护，但对正常数据无影响 |
| `C_f` | 边界条件写法 | 方法 A：`if len <= 2: return 0.0`（提前返回）；方法 B：`... if len > 2 else zeros`（三元表达式）。逻辑等价 |
| `epsilon_2x` | 完全一致 | — |
| `SC_res_mean` | 完全一致 | — |
| `I_burst` | 完全一致 | — |

**总结**：两种方法在数学公式层面完全等价，仅在空值/边界保护的写法上存在无实质影响的形式差异。

## 6. 结论

1. **两个 notebook 的数据处理流程完全相同**：均对整条信号预处理一次，再对 20 ms / 50% 重叠的滑窗逐窗口提取特征，不存在"整段信号计算特征"与"滑窗计算特征"的差异。

2. **五个特征的计算公式完全等价**：build-3 的内联自定义函数是对 `compute_all_features` 中对应逻辑的提取复刻，两者数学上无差异。

3. **数值验证结果为零差异**：在 999 个窗口上，所有五个特征的绝对差均为 0，结果完全一致，符合预期。

4. **两个 notebook 的主要区别不在特征计算逻辑，而在工程结构上**：
   - build-3 只计算 5 个目标特征（轻量），并行粒度为窗口级，直接支持 TDMS 输入
   - batch 调用 `compute_all_features` 计算全量特征集，适合全特征探索场景
