# PCCP纯流噪声与混合信号判别技术文档

## 执行摘要

本技术文档面向这样一个更贴近现场的判别任务：**区分“纯流噪声事件”与“混合信号事件”**，其中混合信号指“流噪声鼓包 + 断丝瞬态”同时出现。该任务的难点，不在于断丝信号本身是否存在，而在于断丝往往被高频、频带重叠、持续出现的流噪声所淹没；因此，单纯依赖总能量、最大幅值、持续时间或静态频带宽度，通常不足以稳定地区分两类事件。PCCP 断丝是失效的重要因素，已有监测研究也指出，断丝信号一般表现为**高幅值、短持续时间**；同时，已有 PCCP 研究在构造识别数据集时，明确将采集到的断丝信号与运行管道中的噪声进行叠加后再进行识别，这与本任务“混合信号检测”的工程背景高度一致。

从信号建模角度看，本报告建议把“鼓包流噪声”视为**局部近谐波、幅频缓慢变化的 AM-FM 结构化成分**，把“断丝”视为**短时突发、快速衰减的阻尼振荡/宽带瞬态成分**。这与时频分析领域对“局部近谐波、缓慢变化分量”以及对“指数阻尼正弦成分”的经典建模是一致的，因此，最合理的思路不是把原始波形直接扔给一个黑箱分类器，而是先解释掉“可预测的流噪声主结构”，再在**残差**中检测是否存在额外的断丝瞬态。

基于这一认识，本报告提出一条**可解释、可工程落地、对样本规模要求较低**的主线方案：
**“主结构建模 + 残差异常检测 + 双评分融合”**。
其中，主结构建模部分用时频 ridge、包络拟合、二倍频一致性和流噪声重构误差来描述“一个事件有多像纯鼓包”；残差异常检测部分用残差高频能量、局部谱峭度、阻尼原子匹配、矩阵铅笔/Prony 类阻尼参数估计、双字典稀疏分解等特征来描述“鼓包之外是否多出一个短时损伤分量”。该设计直接利用了 STFT、Hilbert 解析信号、谱峭度、匹配追踪、K-SVD 和小波包等成熟方法，方法来源清楚，可逐步实现，不依赖端到端深度网络才能工作。

从工程实施角度，本报告建议把整套系统设计为**两级处理链**。一级链路使用带通、稳健归一化、双分辨率 STFT/短时 PSD、ridge 提取、包络拟合和若干低复杂度特征，实现实时筛查；二级链路仅在候选事件上运行阻尼原子匹配、矩阵铅笔法和双字典稀疏分解，从而在不显著增加总计算量的前提下提升对低 SNR 混合事件的检出能力。由于 STFT 和 Hilbert 都可基于 FFT 高效实现，而匹配追踪、字典学习和矩阵铅笔属于更重但更有判别力的候选增强模块，因此这种“轻前端、重后端”的结构最符合实时系统的部署习惯。

从评价体系角度，本报告建议以**事件级 Recall、Precision、F1、PR-AUC、ROC-AUC、事件误报率、短窗误报率、置信度校准**作为主指标，而不把总体准确率作为核心指标。理由是：在混合事件通常稀少、纯流噪声大量出现的工况下，正负样本往往不平衡，ROC 仍有价值，但 PR 曲线和 PR-AUC 往往更能反映少数类的真实检出质量；因此，门限选择应以 PR 表现优先、ROC 辅助，并把现场误报成本纳入调参目标。

综合而言，本报告的主张非常明确：**不要把任务理解为“断丝 vs 流噪声”的普通二分类，而应理解为“在结构化流噪声背景中检测额外瞬态损伤分量”**。围绕这一目标，最推荐优先落地的特征组合是：**包络鼓包拟合误差、主 ridge 连续率、二倍频一致性、流噪声主结构重构误差、残差高频能量比、残差最大谱峭度、阻尼原子最大匹配度、加入损伤原子后的误差下降率**。若这些特征构成的双评分系统已经达到目标检出率和误报率，再进一步考虑双字典在线自适应或小规模深度学习增强，会更稳妥。

## 问题定义与假设

**问题定义**

本文档讨论的目标类别定义如下：

- **纯流噪声类**：事件主体表现为鼓包形包络、主频随时间变化、常伴随稳定二倍频/谐波结构，但不包含可确认的额外断丝瞬态。
- **混合信号类**：同样存在鼓包流噪声主结构，但在其内部或边沿叠加了一个短时、高突发、快衰减、与原主频轨迹不一致的断丝分量。

为了便于后续算法表达，定义观测信号为：

$$
x(t)=x_f(t)+y\cdot x_d(t)+n(t),\quad y\in \{0,1\}
$$

其中 $x_f(t)$ 表示流噪声主结构，$x_d(t)$ 表示断丝损伤分量，$n(t)$ 表示背景噪声或测量噪声；当 $y=0$ 时为纯流噪声，当 $y=1$ 时为混合信号。将流噪声写成局部近谐波 AM-FM 形式、将断丝写成指数阻尼正弦叠加形式，分别对应经典时频分析与阻尼参数估计的标准建模思路。

**已知项、未指定项与本文默认处理**

| 项目 | 当前状态 | 本文默认值/处理方式 | 影响说明 |
|---|---|---|---|
| 采样率 $f_s$ | 未指定 | 统一用“毫秒 + 采样点公式”给参数；若需保留 60 kHz 上限，前端采样与模拟链路必须覆盖该频段 | 直接影响窗口长度、频率分辨率、WPT 分解层数与上限频带可用性 |
| 单事件时长 | 已知，约 0.01 s | 以 10 ms 为主设计，允许 2–12 ms 可调 | 决定 STFT 时间分辨率与候选残差窗长度 |
| 目标频带 | 已知，约 5–60 kHz | 一级处理默认带通 5–60 kHz；若 $f_s$ 不足则上限降到 $0.8\,f_N$ | 决定 ridge 搜索区间与残差高频带定义 |
| 纯流噪声形态 | 已知现象 | 视为鼓包包络 + 时变基频 + 二倍频/谐波结构 | 是主结构建模的对象 |
| 断丝形态 | 已知现象 + 工程建模 | 视为短时突发、快衰减、可能含高频阻尼振荡 | 是残差异常检测的对象 |
| 标签平衡性 | 未指定 | 按“混合类偏少、纯噪声偏多”的不平衡场景设计评价与门限 | 指标与门限选择以 PR 优先 |
| 触发前背景窗 | 未指定 | 若可获得，建议保留至少 1–2 ms 预触发；若无法获得，则用事件外缘估计基线 | 影响 SNR、前后不对称度、背景分位门限 |
| 多通道信息 | 未指定 | 默认按单通道处理；若多通道可用，建议后续做空间一致性增强 | 本文不依赖多通道即可成立 |
| 纯净断丝样本 | 稀缺 | 不要求大量纯净、高 SNR 断丝样本；以模型驱动 + 少量基线纯噪声实现 | 决定优先采用可解释方法而非重监督方法 |

**核心假设**

本文明确采用以下工程假设：其一，**鼓包流噪声具有比断丝更强的“可建模性”**，至少可被主 ridge、谐波比和包络函数较好描述；其二，断丝在混合事件中虽可能很弱，但仍会在局部时间内留下额外的高频、突发、阻尼、模型失配或稀疏系数异常；其三，由于混合事件通常是少数类，因此评价阶段必须优先关注 PR 指标而不能只看总准确率。该假设与已有 PCCP 研究中“时间域简单特征能区分断丝与噪声”的结论并不矛盾，而是向更困难的“叠加场景”推进了一步。

## 背景与机理分析

PCCP 的承载性能高度依赖预应力钢丝，断丝被认为是 PCCP 失效的重要因素之一；已有文献指出，PCCP 突发破坏通常几乎没有充分预警，而断丝又可能是走向破坏前的关键中间事件，因此断丝监测与识别是实际运维中的高价值任务。近年的 DAS/PCCP 研究也反复强调，断丝事件在时域上常呈现**高幅值、短持续时间**，而传统分析中，幅值、持续时间、短时过零率与短时能量等指标对“断丝 vs 一般噪声”已有一定区分效果。

但本任务的难点恰恰在于：你要识别的不是“纯断丝”，而是**“流噪声主结构中是否额外叠加了断丝”**。这类问题已经在 PCCP 相关研究中以另一种形式出现过：有研究为了训练识别模型，显式地把采集到的断丝信号与运行管道噪声进行组合，再基于时频图进行识别。这说明“断丝在运行噪声背景中被识别”并不是边缘问题，而是工程上真实存在的问题。只不过，本文不优先走大样本深度学习路线，而是优先构建一个可解释、参数可控、对样本量不敏感的检测方案。

从信号机理上看，把流噪声建模为**局部近谐波、慢变幅频的结构化分量**是合理的。时频分析文献把这一类信号描述为“由少量在时频平面上分离的分量叠加而成，每个分量可视为局部近谐波且其幅值与频率缓慢变化”；此类信号尤其适合用 STFT、CWT、同步压缩等方法表征其瞬时频率轨迹与谐波结构。结合本任务的先验观察，可以进一步把纯流噪声事件视作“鼓包包络 + 主频轨迹 + 二倍频/谐波 + 宽带背景”的组合。

与之对应，断丝事件更适合用**短时阻尼振荡或宽带瞬态**来描述。矩阵铅笔法所针对的标准模型，正是“由若干指数阻尼/不阻尼正弦在噪声中叠加而成的序列”，其待估参数直接包括频率与阻尼因子，并且原始论文明确指出：相对多项式/Prony 形式，矩阵铅笔法在这类参数估计问题上计算更高效、对未知阻尼因子的噪声敏感性更低。对于本任务中的混合信号，这为“在残差里检查是否存在断丝样的阻尼分量”提供了很强的理论支撑。

频带重叠之所以构成挑战，是因为 PSD 或总带宽只能看到“能量在哪些频率”，却并不保留“这些能量是否来自持续谐波主结构、是否在局部出现瞬态异常、是否遵循原有二倍频关系”。谱峭度文献正是针对这一问题提出：PSD 会“抹掉”非平稳信息，而谱峭度可以指出“瞬态序列在频域中的位置”，并且可由 STFT 给出可实现的估计器。因此，在 5–60 kHz 频带重叠条件下，**能否把宽带、快衰减、与主 ridge 不一致的额外分量从主结构中剥离出来**，就成为判别的核心。

还应特别注意传播路径问题。AE/WPT 研究指出，在传播距离增加时，AE 频率内容可能保持相对稳定，但幅值会显著衰减；这意味着绝对幅值类门限、绝对高频能量门限在不同安装点位、不同传播路径或不同耦合状态下并不稳健。因此，本文不建议仅依赖绝对峰值和绝对带通能量，而更强调**相对量**：如主结构拟合误差、残差能量占比、二倍频一致性破坏度、加入损伤原子后的误差下降率等。

## 目标与评价指标

**目标定义**

本方案的直接目标是：在单个候选事件层面，为每个事件输出以下结果：

1. 二分类结果：纯流噪声 / 混合信号。
2. 概率分数：$P_{\text{mix}}\in[0,1]$。
3. 置信度分数：$C\in[0,1]$。
4. 可解释证据：至少返回 3 个最主要触发特征，例如“残差高频能量升高”“二倍频一致性明显变差”“阻尼原子匹配度高”。

这种输出形式便于工程联调，因为它不是只给一个标签，而是允许你追溯“为什么判成混合”。已有 PCCP 研究中的传统时间域判别与深度学习频谱图判别都证明了“断丝/噪声界面”本身具有可检测性；本文是在此基础上，改造成更适合运行噪声叠加情形的可解释方案。

**推荐评价指标**

在混合类通常偏少的前提下，不建议把“总体准确率”作为首要验收指标。ROC 图在分类器比较上仍然有价值，但 Fawcett 指出 ROC 的解释与类别分布、误判成本密切相关；Saito 与 Rehmsmeier 进一步指出，当类别明显不平衡时，PR 曲线与 PR-AUC 往往更能真实描述少数类检测质量。因此，本任务应至少同时报告事件级 Recall、Precision、F1、ROC-AUC、PR-AUC，并对误报率作独立统计。

**建议验收指标与目标值**

下表给出建议采用的指标体系。表中目标值属于**工程建议目标**，不是文献中的普适标准，应按现场误报成本与检修容忍度进一步细化。

| 指标 | 含义 | 建议目标 |
|---|---|---|
| 混合事件 Recall | 真混合事件被检出的比例 | 实验室离线 ≥ 95%；现场试运行 ≥ 90% 起步 |
| 混合事件 Precision | 判为混合的事件中真正混合的比例 | ≥ 90%，若误报成本高可提高到 ≥ 95% |
| F1 | Recall 与 Precision 的调和平均 | ≥ 0.92 |
| PR-AUC | 少数类总体检测质量 | 作为主验收曲线面积，越高越好 |
| ROC-AUC | 总体阈值可分性 | 作为辅助指标，越高越好 |
| 事件级误报率 | 纯流噪声被误判为混合的比例 | ≤ 2% 起步，优化目标 ≤ 1% |
| 短窗误报率 | 运行时短窗级误报 | 可按站点定义，建议控制在 $10^{-3}$ 级或更低 |
| 低置信度占比 | 无法稳定决策的样本比例 | 越低越好，建议 < 10% |
| 推理时延 | 单事件从输入到输出的耗时 | 一级实时；二级仅对候选触发 |

**门限优化原则**

建议优先按 PR 曲线选门限，再用 ROC、误报率与检修成本做二次约束。原因是：如果混合事件是少数类，ROC 对类别不平衡的敏感性不够强，而 PR 能更直观地反映“报出来的告警有多少是真的”。同时，建议同时报告**固定门限性能**与**按目标误报率反推门限性能**两套结果，以便算法与运维双方达成一致。

## 总体方法框架

本报告推荐的总体框架可概括为：

$$
\text{预处理} \rightarrow \text{时频主结构建模} \rightarrow \text{流噪声重构} \rightarrow \text{残差构建} \rightarrow \text{损伤异常检测} \rightarrow \text{评分融合与决策}
$$

其思想不是“任何奇怪能量都当断丝”，而是先判断：**这个事件能否被“纯鼓包流噪声模型”较好解释**；如果不能，再去量化这部分“解释不了的残差”有没有呈现断丝应有的阻尼瞬态特征。STFT 为局部时频结构提供基础表征；Hilbert 解析信号用于包络与局部相位/瞬时频率分析；同步压缩可在 ridge 模糊时提高时频集中度；STFT 掩膜重构或 OLA/iSTFT 可用来构建流噪声主分量；残差中的瞬态再由谱峭度、阻尼原子匹配、矩阵铅笔法和双字典稀疏分解进行二次确认。

**推荐信号模型**

为保证方案可解释，建议在工程文档中明确写出下列两类模型：

$$
x_f(t)\approx \sum_{k\in\{1,2\}} a_k(t)\cos\!\left(2\pi\int_0^t f_k(\tau)\,\mathrm{d}\tau+\phi_k\right)+b(t)
$$

其中 $f_2(t)\approx 2f_1(t)$，$a_k(t)$ 为鼓包包络调制，$b(t)$ 为宽带背景或未建模部分。该写法直接对应“基频 + 二倍频 + 时变包络”的流噪声主结构。对于断丝分量，推荐使用：

$$
x_d(t)\approx \sum_{m=1}^{M} A_m e^{-\alpha_m(t-t_0)}\cos\!\left(2\pi f_m(t-t_0)+\theta_m\right)u(t-t_0)
$$

其中 $t_0$ 为损伤触发时刻，$\alpha_m$ 为衰减因子。这个形式与矩阵铅笔法所针对的指数阻尼正弦模型一致。

**体系结构建议**

从实施优先级看，建议分三层落地：

- **基线层**：带通、稳健归一化、双分辨率 STFT/短时 PSD、ridge 提取、包络拟合、二倍频一致性、残差高频能量、局部谱峭度、规则或线性评分器。
- **增强层**：STFT 掩膜重构后的残差阻尼原子匹配、矩阵铅笔法拟合、加入损伤原子后的误差下降率。
- **进阶层**：双字典稀疏分解、K-SVD 离线适配字典、轻量深度学习作为第二阶段重评分器。

这种分层结构能保证：即使只实现基线层，也能先得到可解释结果；后续若误报率或低 SNR 检测率仍不满意，再逐步打开增强层和进阶层。

## 详细处理流程与算法

**推荐处理流程总表**

下表给出的流程按照“先低复杂度、后高复杂度”的原则组织，适合直接转成工程任务单。

| 步骤 | 输入 | 输出 | 推荐算法/方法 | 默认参数建议 |
|---|---|---|---|---|
| 预处理 | 原始事件波形 | 带通信号 $x_b(t)$ | 带通 + 去直流 + 稳健归一化 | 带通 5–60 kHz；归一化用 median/MAD |
| 双分辨率时频分析 | $x_b(t)$ | 标准谱图 $S_m$、短窗谱图 $S_s$ | STFT 或现有短时 PSD；必要时同步压缩 | 标准窗 0.5–0.8 ms；短窗 0.2–0.4 ms；重叠 75–87.5% |
| 主结构提取 | $S_m$ | $\hat f_1(t), \hat f_2(t)$ | ridge 搜索 + 动态规划平滑 | 主频搜索 5–30 kHz；二倍频按 $2\hat f_1$ 附近搜 |
| 包络建模 | $x_b(t)$ | $a(t), \hat a(t)$ | Hilbert 包络 + 双侧高斯/raised-cosine 拟合 | 包络平滑窗 0.1–0.3 ms |
| 主分量重构 | $X[n,k]$、ridge | $\hat x_f(t)$ | STFT 掩膜重构/iSTFT 或简化谐波合成 | ridge 带宽 $\Delta f=\max(2\,\text{bin}, 0.08\hat f)$ |
| 残差构建 | $x_b(t), \hat x_f(t)$ | $r(t)$ | 直接相减或时频域掩膜后重构再相减 | 候选残差窗 0.6–2 ms |
| 瞬态异常检测 | $r(t)$ | 瞬态证据 | 高频能量比、局部谱峭度、阻尼原子匹配、矩阵铅笔 | 高频带 25–60 kHz；阻尼常数 0.1–2 ms |
| 稀疏增强 | $x_b(t)$ 或 $r(t)$ | 稀疏系数 | 匹配追踪/OMP + 双字典；可选 K-SVD | 固定字典起步，离线再适配 |
| 评分与决策 | 全部特征 | $P_{\text{mix}}, C$ | 规则融合 / 线性评分 / 逻辑回归 | 门限由 PR 优先调参 |

Allen 与 Rabiner 将 STFT 表述为由窗函数选择被分析的局部信号后进行频谱分析；若现场系统已经输出滑窗短时 PSD，也可以直接沿用，因为 Welch 方法本质上也是对分段信号的修正周期图进行平均估计。对于本任务，标准窗负责看清鼓包主结构与低频谐波，短窗负责更敏感地检测局部瞬态与高频衰减。

**步骤化实现建议**

第一步是预处理。建议使用**带通 + 去直流 + 稳健幅值归一化**。稳健归一化推荐：

$$
x_n(t)=\frac{x_b(t)-\mathrm{median}(x_b)}{1.4826\cdot \mathrm{MAD}(x_b)+\varepsilon}
$$

这样做的目的不是“去掉所有幅值信息”，而是减少不同安装条件、增益配置和传播路径对后续门限的影响。若可获得预触发背景窗，应额外保存 1–2 ms 作为本地噪声基线。AE 研究表明，传播距离变化会显著改变幅值，因此这一步是必要的，而不是可有可无。

第二步是时频分析。建议至少同时生成两套表示：一套标准 STFT/短时 PSD（偏重频率分辨率）和一套短窗 STFT（偏重时间分辨率）。若主 ridge 在普通谱图上过于发散，可对标准谱图进一步做同步压缩。同步压缩文献表明，它适合于由少量局部近谐波、缓变分量构成的信号，并且在噪声存在时仍能提供较集中的瞬时频率轨迹。

第三步是 ridge 提取。动态规划式 ridge 提取可直接写成“最大化每一时刻谱能量，同时惩罚相邻时刻频率跳变”的问题。尽管经典示例来自 CWT scalogram，但“从时频能量图中用动态规划抽取主 ridge”的思想可以直接移植到本任务的 STFT/同步压缩图上，用于跟踪 $\hat f_1(t)$ 与 $\hat f_2(t)$。

第四步是包络拟合。解析信号可通过把负频率置零、正频率加倍的 FFT 方式得到，其模值即包络。建议用双侧高斯或 raised-cosine 拟合鼓包包络，拟合误差本身就是一项重要特征；若鼓包天然存在轻微偏斜，则双侧高斯会比单对称高斯更稳健。

第五步是主分量重构与残差构建。与其直接在时域拟合相位，不如优先使用**时频掩膜重构**：保留 ridge 邻域及其谐波邻域能量，其他部分以残差形式留下。Allen 与 Rabiner 对 STFT 的分析-重构关系给出了可逆性讨论，因此在满足合适窗函数和重叠条件时，用 iSTFT 重构 $\hat x_f(t)$ 是合理且工程上更稳定的做法。

第六步是对残差做瞬态检测。谱峭度特别适合在强噪声环境中寻找瞬态位置；断丝如果真的叠加在鼓包上，通常会导致残差中的高频瞬态和局部非高斯性明显增强。阻尼拟合部分可先用字典匹配做快速搜索，再在最可疑的短窗上调用矩阵铅笔法估计阻尼和频率，作为高置信确认。

第七步是稀疏增强。用一个流噪声字典 $D_f$（谐波 chirplet、AM-FM 原子、鼓包包络原子）和一个损伤字典 $D_d$（冲击/阻尼正弦原子）对信号做联合稀疏分解：

$$
x \approx D_f\alpha_f + D_d\alpha_d
$$

若 $\alpha_d$ 的相对能量或 $l_1$ 质量显著上升，则可作为混合类的重要证据。若后续积累到足够多高置信纯流噪声和高置信混合样本，可离线用 K-SVD 对字典做自适应更新。

**主流程伪代码**

```text
输入:
    x(t), fs
输出:
    label ∈ {纯流噪声, 混合信号}, P_mix, C, evidence

1. x_b ← bandpass(x, 5kHz, 60kHz or 0.8*Nyquist)
2. x_n ← robust_normalize(x_b)              # median/MAD
3. S_m ← STFT(x_n, T_w=0.5~0.8ms, overlap=75%)
4. S_s ← STFT(x_n, T_w=0.2~0.4ms, overlap=87.5%)
5. 如 ridge 发散，则 S_m ← synchrosqueeze(S_m)

6. f1(t) ← ridge_track(S_m, band=5~30kHz)
7. f2(t) ← harmonic_ridge_track(S_m, around=2*f1(t))
8. a(t)  ← abs(hilbert(x_n))
9. a_hat(t) ← fit_bulge_envelope(a(t))      # 双侧高斯或 raised-cosine

10. X_f ← ridge_mask_reconstruct(S_m, f1(t), f2(t), bandwidth=Δf)
11. x_f_hat ← iSTFT(X_f)
12. r(t) ← x_n - x_f_hat

13. 计算主结构特征:
        ridge continuity, harmonic ratio, envelope fit error, reconstruction error
14. 计算残差特征:
        HF residual energy, max spectral kurtosis, local kurtosis/crest,
        damped atom matching, matrix-pencil damping, optional WPT and sparse ratio

15. S_flow ← weighted_sum(flow-consistency features)
16. S_dmg  ← weighted_sum(residual-anomaly features)
17. P_mix  ← sigmoid(S_dmg - β*S_flow + b)
18. C      ← confidence(P_mix, signal_quality)

19. if P_mix ≥ τ_H and C ≥ τ_C:
        label ← 混合信号
    else if P_mix ≤ τ_L and C ≥ τ_C:
        label ← 纯流噪声
    else:
        label ← 按最近类输出并打低置信标记

20. evidence ← top-3 contributing features
```

上面的主流程把 STFT/Hilbert/谱峭度/阻尼拟合/稀疏增强都放进了同一条工程链中，但实现时完全可以按“基线层→增强层→进阶层”逐步打开。

**ridge 提取伪代码**

```text
输入:
    时频能量图 S[n, k]
输出:
    ridge k_hat[n]

目标函数:
    J = Σ_n log(S[n, k_n] + ε) - λ1 Σ_n |k_n - k_{n-1}| - λ2 Σ_n |Δk_n - Δk_{n-1}|

动态规划:
1. 初始化第一帧所有频点代价
2. 对 n = 2...N:
       对每个频点 k:
           在允许转移集合 Ω(k) 内寻找最优前驱 p
           DP[n, k] = DP[n-1, p] + log(S[n, k] + ε)
                      - λ1|k-p| - λ2|(k-p) - (p-p_prev)|
3. 回溯得到 k_hat[n]
4. 对二倍频 ridge:
       在 k ≈ 2*k_hat[n] 附近重复上述过程
```

动态规划 ridge 跟踪的核心思想来自对时频能量图中“最大响应轨迹”的连续提取；该思想已在 CWT ridge 提取中得到验证，本报告将其移植到谱图/同步压缩图上。

**双字典稀疏分解伪代码**

```text
输入:
    x_n(t) 或 r(t)
输出:
    α_f, α_d, η_dict

1. 构造流噪声字典 D_f:
       谐波 AM-FM 原子、鼓包包络原子、chirplet 原子
2. 构造损伤字典 D_d:
       冲击原子、阻尼正弦原子、短时宽带原子
3. 用 OMP / Matching Pursuit 解:
       min ||x - D_f α_f - D_d α_d||_2^2
       s.t. ||α_f||_0 + ||α_d||_0 ≤ K
4. 计算:
       η_dict = ||α_d||_1 / (||α_f||_1 + ||α_d||_1 + ε)
5. 若已有足够高置信样本:
       用 K-SVD 离线更新 D_f, D_d
```

匹配追踪提供了从冗余时频字典中自适应选取原子以逼近信号结构的方法；K-SVD 则提供了在稀疏约束下更新字典、让字典更贴合训练样本的办法，因此二者天然适合作为“固定解析字典 → 离线适配字典”的连续升级路线。

## 特征清单与判别逻辑

下表综合了 STFT/Hilbert、谱峭度、阻尼参数估计、匹配追踪、K-SVD 与 WPT 的原理，并结合“事件长约 10 ms、频带 5–60 kHz、采样率未指定”的工况给出**可调默认值**。优先级分为 **P0（建议首批实现）**、**P1（建议增强）**、**P2（可选优化）**。这些特征并不局限于时域、频域、时频域、小波和形态学五类，而是显式加入了**模型失配、阻尼原子匹配、稀疏表示**等更贴合本任务本质的特征。

| 特征名 | 类别 | 计算方法 | 窗口/参数 | 预期行为 | 优先级 |
|---|---|---|---|---|---|
| 主 ridge 连续率 $\rho_r$ | 主结构一致性 | $\rho_r=L_{\text{valid}}/L_{\text{all}}$ | 标准窗 0.5–0.8 ms；75% overlap | 纯噪声高，混合略降 | P0 |
| 主 ridge 拱形拟合优度 $R^2_{\text{ridge}}$ | 主结构一致性 | 对 $\hat f_1(t)$ 做二次或样条拟合取 $R^2$ | ridge 搜索 5–30 kHz | 纯噪声高，混合降低 | P0 |
| 二倍频一致性误差 $\varepsilon_{2\times}$ | 谐波一致性 | $\mathrm{median}\!\left\{\frac{\lvert f_2(t)-2f_1(t)\rvert}{f_1(t)}\right\}$ | 二倍频邻域 $\pm\max(2\,\text{bin}, 0.08f_1)$ | 纯噪声低，混合升高 | P0 |
| 谐波能量占比 $R_{\text{harm}}$ | 谐波一致性 | ridge 邻域能量 / 总能量 | 基频 + 二倍频 $\pm\Delta f$ | 纯噪声高，混合下降 | P0 |
| 包络鼓包拟合误差 $\varepsilon_{\text{env}}$ | 包络形态 | $\frac{\lVert a-\hat a\rVert_2}{\lVert a\rVert_2}$ | Hilbert 包络；平滑 0.1–0.3 ms | 纯噪声低，混合升高 | P0 |
| 包络左右宽度比 $\eta_{\text{bw}}$ | 包络形态 | $\frac{t_{95}-t_p}{t_p-t_{05}}$ | 包络百分位 5/95% | 纯噪声接近稳定范围，混合偏离 | P1 |
| 流噪声重构误差 $\varepsilon_{\text{rec}}$ | 模型失配 | $\frac{\lVert x-\hat x_f\rVert_2^2}{\lVert x\rVert_2^2}$ | STFT 掩膜重构 | 纯噪声低，混合高 | P0 |
| 残差高频能量比 $R_{\text{HF,res}}$ | 残差瞬态 | $\frac{E_r(25\!-\!60\text{kHz})}{E_x(5\!-\!60\text{kHz})}$ | 高频带默认 25–60 kHz，可调 | 纯噪声低，混合高 | P0 |
| 残差最大谱峭度 $SK_{\max}$ | 残差瞬态 | $\max_k \widehat{SK}[k]$ | 用短窗 STFT 估计 | 纯噪声低，混合高 | P0 |
| 残差局部峭度 $K_{\text{loc}}$ | 残差瞬态 | 候选窗内 kurtosis | 候选窗 0.2–0.5 ms | 纯噪声低，混合高 | P1 |
| 残差峰均比 $CF_{\text{res}}$ | 残差瞬态 | $\frac{\max\lvert r\rvert}{\mathrm{RMS}(r)}$ | 候选窗 0.2–1.0 ms | 纯噪声低，混合高 | P1 |
| 阻尼原子最大匹配度 $C_{\text{damp}}$ | 阻尼证据 | $\frac{\max_\theta \lvert\langle r,g_\theta\rangle\rvert}{\lVert r\rVert\,\lVert g_\theta\rVert}$ | $f=8\!-\!45$ kHz；$\tau_d=0.1\!-\!2$ ms | 纯噪声低，混合高 | P0 |
| 残差衰减常数 $\hat\alpha$ | 阻尼证据 | 对残差包络对数线性拟合求斜率 | 触发后 0.3–1.5 ms | 混合更易出现稳定正衰减 | P1 |
| 矩阵铅笔拟合优度 $Q_{\text{MP}}$ | 阻尼证据 | 指数阻尼正弦拟合的误差下降率 | 仅对候选窗调用 | 纯噪声低，混合高 | P1 |
| 增加损伤原子后的误差下降率 $\Delta J$ | 模型竞争 | $\frac{\lVert x-\hat x_f\rVert^2-\lVert x-\hat x_f-\hat x_d\rVert^2}{\lVert x\rVert^2}$ | $\hat x_d$ 用阻尼原子或小字典求得 | 纯噪声低，混合高 | P0 |
| WPT 高频-低频能差 $D_{\text{WPT}}$ | 多分辨率能量 | $\sum_{i\in HF}p_i-\sum_{i\in Harm}p_i$ | 选 $J$ 使子带带宽约 2–5 kHz | 纯噪声低，混合高 | P1 |
| 字典损伤系数比 $\eta_{\text{dict}}$ | 稀疏表示 | $\frac{\lVert \alpha_d\rVert_1}{\lVert \alpha_f\rVert_1+\lVert \alpha_d\rVert_1}$ | OMP/MP；$K$ 可取 4–12 | 纯噪声低，混合高 | P1 |
| ridge 缺口率 $G_{\text{gap}}$ | 结构破坏 | 主 ridge 中断帧数 / 总帧数 | 与 $\rho_r$ 同 | 纯噪声低，混合高 | P2 |
| 残差前后不对称度 $\eta_{\text{asym}}$ | 触发局部形态 | $\frac{E[t_0,t_0+\tau]}{E[t_0-\tau,t_0]}$ | $\tau=0.3\!-\!1.0$ ms | 混合更易显著 > 1 | P2 |

上表中有几组符号在工程实现时需要统一口径。$\hat f_1(t)$ 和 $\hat f_2(t)$ 分别表示主 ridge 与二倍频 ridge 的瞬时频率轨迹；$\rho_r$ 中的 $L_{\text{valid}}$ 为 ridge 成功跟踪的有效帧数，$L_{\text{all}}$ 为事件总帧数。$R_{\text{harm}}$ 的“ridge 邻域能量”建议定义为基频与二倍频两条 ridge 附近 $\pm\Delta f$ 带宽内的积分能量，其中 $\Delta f$ 取 2 个频率 bin 与 $0.08f_1(t)$ 的较大者。$\varepsilon_{\text{env}}$ 反映包络与“标准鼓包”模型的失配程度，数值越大说明越不像纯流噪声鼓包；$\eta_{\text{bw}}$ 则刻画峰值左右两侧包络展宽是否对称。$E_r(\cdot)$ 与 $E_x(\cdot)$ 分别是残差信号和原始事件在指定频带上的积分能量，因此 $R_{\text{HF,res}}$ 是“高频异常占总能量比例”的量。$K_{\text{loc}}$ 是候选短窗内的时域 kurtosis，$CF_{\text{res}}$ 是同一短窗内的 crest factor。$C_{\text{damp}}$ 衡量残差与阻尼正弦原子的最大归一化相关度；$Q_{\text{MP}}$ 表示矩阵铅笔法引入阻尼指数正弦后带来的拟合误差下降程度；$\Delta J$ 则是“加入损伤原子前后”整体重构误差的相对下降率。$D_{\text{WPT}}$ 中的 $HF$ 与 $Harm$ 分别表示高频子带集合与主谐波相关子带集合；$\eta_{\text{dict}}$ 表示稀疏分解中“损伤字典系数占比”；$\eta_{\text{asym}}$ 用来判断触发后能量是否明显偏向后沿。

**关键特征的推荐公式**

建议在正式实现中把以下四类特征作为主干。

第一类是**主结构一致性特征**。标准谱图按 STFT 定义计算：

$$
X[n,k]=\sum_{m=0}^{L_w-1}x[m+nH]\,w[m]\,e^{-j2\pi km/L_w},\qquad
S[n,k]=|X[n,k]|^2
$$

由其提取 $\hat f_1(t)$ 与 $\hat f_2(t)$，再计算 $\rho_r, R^2_{\text{ridge}}, \varepsilon_{2\times}, R_{\text{harm}}$。这些量反映“事件是否仍保持鼓包流噪声原有的时变谐波骨架”。

第二类是**包络形态特征**。解析信号 $x_a=x+j\mathcal{H}\{x\}$ 的模值 $a(t)=|x_a(t)|$ 作为事件包络，推荐用双侧高斯鼓包拟合：

$$
\hat a(t)=
\begin{cases}
A\exp\!\left(-\dfrac{(t-\mu)^2}{2\sigma_l^2}\right), & t\le \mu \\
A\exp\!\left(-\dfrac{(t-\mu)^2}{2\sigma_r^2}\right), & t> \mu
\end{cases}
$$

再由 $\varepsilon_{\text{env}}$ 和 $\eta_{\text{bw}}$ 量化其与“正常鼓包”的偏离。

第三类是**残差瞬态特征**。先用 ridge 掩膜构建流噪声主分量：

$$
\hat X_f[n,k]=X[n,k]\cdot \mathbf{1}\!\left(|k-k_1(n)|\le \Delta k_1 \;\text{or}\; |k-k_2(n)|\le \Delta k_2\right)
$$

$$
\hat x_f(t)=\mathrm{iSTFT}(\hat X_f), \qquad r(t)=x(t)-\hat x_f(t)
$$

然后在 $r(t)$ 或其短窗谱图上计算 $R_{\text{HF,res}}$、$SK_{\max}$、$K_{\text{loc}}$、$CF_{\text{res}}$。谱峭度之所以要纳入，是因为它正是为“在强噪声下定位瞬态及其频段”而提出。

第四类是**阻尼与模型竞争特征**。对残差候选窗，用阻尼原子

$$
g_\theta(t)=e^{-(t-t_0)/\tau_d}\cos(2\pi f_d (t-t_0)+\phi)\,u(t-t_0)
$$

做匹配，取最大相关度 $C_{\text{damp}}$；对更高置信候选，再用矩阵铅笔法估计 $(f_d,\alpha)$ 并构造 $Q_{\text{MP}}$。此外，最有解释力的竞争特征之一是：

$$
\Delta J=\frac{\|x-\hat x_f\|_2^2-\|x-\hat x_f-\hat x_d\|_2^2}{\|x\|_2^2}
$$

如果加入一个损伤原子后拟合显著改善，则很难再把该事件解释为“纯鼓包”。

**门限建议**

门限不建议一开始设置为固定绝对值，而建议按**站点基线分位数**进行。具体可采用以下默认策略：

- 对“值越大越像混合”的特征（如 $R_{\text{HF,res}}, SK_{\max}, C_{\text{damp}}, \Delta J, \eta_{\text{dict}}$），初始门限取纯流噪声基线的 $q_{0.99}$；若误报偏高，可提升到 $q_{0.995}$。
- 对“值越小越像纯流噪声”的一致性特征（如 $\rho_r, R_{\text{harm}}, R^2_{\text{ridge}}$），可将异常门限设在基线的 $q_{0.05}$ 或 $q_{0.01}$。
- 对传播路径敏感的幅值型特征，不用绝对值直接判决，而应换成占比、差值、拟合误差或相对改进率。

这一策略本质上是在做**低样本、解释型异常检测**，与 PR 优先的评价逻辑是一致的。

**评分合成与决策规则**

建议把特征分成两组，分别合成为“流噪声一致性分数”和“损伤残差分数”。

$$
S_{\text{flow}}
= w_1(1-\varepsilon_{\text{env}})
+ w_2\rho_r
+ w_3(1-\varepsilon_{2\times})
+ w_4R_{\text{harm}}
+ w_5R^2_{\text{ridge}}
$$

$$
S_{\text{dmg}}
= u_1\varepsilon_{\text{rec}}
+ u_2R_{\text{HF,res}}
+ u_3SK_{\max}
+ u_4C_{\text{damp}}
+ u_5\Delta J
+ u_6\eta_{\text{dict}}
$$

其中权重建议以“P0 特征优先，P1 特征用于增强”的方式设定，首版可用等权或经验权重，后续再用少量标定数据微调。最终概率可定义为：

$$
P_{\text{mix}}=\sigma(S_{\text{dmg}}-\beta S_{\text{flow}}+b)
$$

这里的权重与门限本身也需要解释。$w_i$ 与 $u_i$ 分别是流噪声一致性特征组和损伤异常特征组的非负权重；$\beta$ 是两组分数的相对平衡系数，控制“多像流噪声”对最终混合概率的抵消强度；$b$ 是偏置项。它们都不是新的物理特征，而是评分器参数。若首版没有标定数据，可先令 P0 特征等权、P1 特征权重减半，并把 $\beta$ 初始设为 1。

若担心过于黑箱，可在首版完全不用逻辑回归，而采用如下可解释规则：

- 若 $\varepsilon_{\text{rec}}>\tau_{\text{rec}}$ 且 $(R_{\text{HF,res}}>\tau_{\text{hf}} \;\text{或}\; SK_{\max}>\tau_{\text{sk}})$，则判为混合；
- 若 $C_{\text{damp}}>\tau_{\text{damp}}$ 且 $\Delta J>\tau_{\Delta J}$，则判为混合；
- 若 $\rho_r, R_{\text{harm}}, R^2_{\text{ridge}}$ 同时良好，而 $R_{\text{HF,res}}, SK_{\max}, C_{\text{damp}}$ 均未超阈，则判为纯流噪声。

这种“主结构一致性 + 残差瞬态异常”的双证据判别规则，比单一能量阈值更符合本任务。

**置信度输出**

建议把置信度定义为“判决距离 × 信号质量”的乘积，例如：

$$
Q = 0.4\rho_r + 0.3R_{\text{harm}} + 0.3(1-\text{clip\_ratio})
$$

$$
C = \min\{1,\; 2|P_{\text{mix}}-0.5|\}\cdot Q
$$

这里 $Q$ 是质量门控项而不是分类概率。其中 $\rho_r$ 衡量 ridge 可跟踪性，$R_{\text{harm}}$ 衡量谐波骨架完整度，$\text{clip\_ratio}$ 表示事件中被削顶或受限幅污染的采样点比例，因此 $(1-\text{clip\_ratio})$ 用来抑制前端饱和导致的虚假高置信度。上面的 $\tau_{\text{rec}}, \tau_{\text{hf}}, \tau_{\text{sk}}, \tau_{\text{damp}}, \tau_{\Delta J}, \tau_H, \tau_L, \tau_C$ 都属于判决门限，不是新的物理量，建议统一由纯流噪声基线分位数或 PR 曲线调参得到。

其中 clip\_ratio 为削顶比例或采集异常比例。输出层可采用**双门限**：

- $P_{\text{mix}}\ge 0.8$ 且 $C\ge 0.6$：混合信号；
- $P_{\text{mix}}\le 0.2$ 且 $C\ge 0.6$：纯流噪声；
- 其余：低置信度，保留复核标记。

若系统必须强制二分类，也应把“低置信标记”作为附加字段对外输出。考虑到类别不平衡，双门限最终仍应以 PR 表现和误报成本来确定。

## 工程实现、验证、风险与扩展

**工程实现建议**

在采样率未指定的前提下，所有窗口参数建议以“毫秒”为主、以“样点数 $L=\lfloor f_sT_w\rfloor$”落地。对于 5–60 kHz 的目标频带，前端采集链路必须真正保留到该上限，否则高频残差特征、WPT 高频能差和阻尼匹配频率上限都需要相应下调。一级链路中，带通、STFT、iSTFT、Hilbert 和基础统计特征都属于轻量模块；二级链路中的阻尼原子匹配、矩阵铅笔法和双字典稀疏分解则应只对候选事件调用。这样可以把实时性与判别力兼顾起来。

在计算复杂度上，可把系统理解为“**FFT 前端 + 候选事件精检后端**”。STFT、短时 PSD 与 Hilbert 都可走 FFT 管线，适合实时运行；匹配追踪、矩阵铅笔和双字典稀疏分解的复杂度更高，但它们只需在事件通过一级筛选后才运行，因此整体负荷仍可控。工程上宜优先实现：预处理、双分辨率谱图、ridge/包络/重构误差、残差高频能量与谱峭度；其后再逐步加入阻尼匹配与稀疏增强。

**验证与测试方案**

建议把验证分成三层。第一层是**合成测试**：从高置信纯流噪声事件出发，按阻尼正弦模型注入不同频率、不同衰减常数、不同触发位置和不同幅值的损伤原子，构造可控 SNR 的混合数据。由于同步压缩和矩阵铅笔法都以局部近谐波/阻尼正弦为基础，这种合成方式与算法假设一致。第二层是**鲁棒性测试**：系统性改变鼓包长度、主频变化速率、二倍频强度、传播衰减、带通上限、预触发背景长度、增益漂移与轻微削顶，统计指标波动。第三层是**现场盲测**：按时间切分或工况切分，观察事件级 Recall、Precision、PR-AUC、误报率与低置信度占比。少数类场景必须优先看 PR-AUC，并单独统计误报成本。

若确实缺乏纯净断丝样本，本方案仍然可推进。原因在于：已有 PCCP 研究表明，运行噪声与断丝混合构成的时频图数据是现实存在的；而本文方案中最关键的检测证据——主结构失配、残差高频、谱峭度和阻尼匹配——都可以在**无大规模混合类标注**的前提下通过模型驱动与基线噪声分位数来实现。也就是说，首版不要求你先采集和标注大量代表性波形；首要任务是先建立“纯鼓包主结构能解释到什么程度”的基线。

**风险与注意事项**

本方案最重要的风险不是“算法不够复杂”，而是**主结构建模不够准确**。如果 ridge 提取失败，或流噪声主分量重构质量很差，那么残差里会混入大量本来属于鼓包的能量，从而抬高误报率。因此，建议先把“纯流噪声事件”的 ridge/包络/重构效果做扎实，再引入残差异常判别。已有 PCCP 研究使用的时间域简单特征虽然能区分“断丝 vs 噪声”，但对本文这种“鼓包内叠加断丝”的场景并不充分，这也是本报告为什么把主结构建模放在第一位。

第二个风险是**路径与安装条件对幅值型特征的扰动**。AE 研究已经指出传播距离会显著改变幅值衰减，因此凡是直接依赖绝对峰值、绝对高频能量的特征，都必须改成占比、相对门限或模型失配量。第三个风险是**上限频带不可用**：若采样与前端并未真实覆盖到 60 kHz，那么所有“25–60 kHz 残差特征”都需要自动降阶。第四个风险是**强削顶或 AGC**：一旦前端对短时冲击做了限幅，局部峭度、峰均比、阻尼拟合都会失真，因此必须把 clip\_ratio 作为质量指标输出。

**后续扩展建议**

在首版可解释方案稳定之后，可以考虑两条扩展路线。第一条是**轻量深度学习重评分**：不直接用原始波形做端到端，而是把“标准谱图 + 残差谱图 + 少量关键手工特征”送入轻量模型做第二阶段排序。PCCP 领域已有将断丝与运行噪声混合后转为时频图再做检测的工作，这说明这条路线有现实基础；但考虑到现场标注成本与可解释性，本文不建议把它作为首选。第二条是**在线自适应字典**：以固定解析字典为初始，在积累高置信样本后，用 K-SVD 离线或半在线更新 $D_f, D_d$，让字典逐渐贴合本站点的鼓包与损伤形态。
