# 2026-05-25 真实数据标签预测 notebook 开发说明

## 1. 目标
- 新增一个可执行 notebook，用于加载 `outputs/model_test_cross_condition_260518-2` 下的 7 组模型，对真实特征数据进行断丝标签预测。
- 支持用户在 notebook 中修改：
  - 特征目录路径（可多目录）；
  - 模型类型（`logistic_regression` / `rbf_svm` / `random_forest`）；
  - 实验组列表（默认全量 7 组）；
  - 阈值与时间连续分段阈值。
- 输出预测统计、正样本时间明细，并按时间连续段绘制概率曲线图。

## 2. 关键约束实现
- 严格保证模型输入特征向量顺序与 `selected_features.csv` 一致：
  - 在预测前固定使用：`x = df.loc[:, selected_features]`；
  - `selected_features` 由各实验目录的 `selected_features.csv` 直接读取，按原顺序使用，不重排。
- 仅使用 Python（UTF-8）读写 `.ipynb`：
  - 新增脚本 `tools/build_realdata_prediction_notebook.py`；
  - 使用 `json.dump(..., ensure_ascii=False, encoding='utf-8')` 写出 notebook；
  - 未使用终端重定向直接改 notebook。

## 3. 新增文件
- `tools/build_realdata_prediction_notebook.py`
  - 作用：生成 notebook 文件；
  - 特点：纯 Python 生成 JSON 结构，带中文注释与配置区。
- `notebooks/2026-05-25-realdata_label_prediction_cross_condition.ipynb`
  - 作用：执行真实数据预测、统计与绘图；
  - 输出：
    - `outputs/realdata_prediction_cross_condition/predictions_<model_type>.csv`
    - `outputs/realdata_prediction_cross_condition/summary_<model_type>.csv`
    - `outputs/realdata_prediction_cross_condition/plots_<model_type>/*.png`

## 4. 中文自检（乱码检查）
- 读取 notebook 的 UTF-8 文本内容后进行自检：
  - 能检测到中文字符；
  - 未检测到 `'?'` 乱码占位符；
  - 核心代码片段存在：`df.loc[:, selected_features]`。

说明：
- 终端在当前环境中显示中文时可能出现编码回显异常，不作为文件实际编码依据；
- 自检基于 Python 按 `encoding='utf-8'` 读取后的内容判断，结果可信。

## 5. 使用步骤
1. 运行：`python tools/build_realdata_prediction_notebook.py`
2. 打开并执行：`notebooks/2026-05-25-realdata_label_prediction_cross_condition.ipynb`
3. 按需修改配置区参数后重跑全部单元格。
