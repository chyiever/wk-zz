# 2026-4-19 特征计算函数开发文档

## 1. 目标

本次开发在 `src/fea_cpt` 下新建了一套可复用的信号特征计算模块，用于覆盖 `doc/特征汇总.md` 中列出的全部特征类别，并支持：

- 单样本和批量样本的统一特征计算。
- 共享中间量复用，减少重复运算。
- 样本 ID、样本名、样本类型编码与特征向量的稳定对应。
- 特征结果、特征向量映射、验证结果、日志文件的落盘保存。
- 常用特征重要性排序方法输出。
- Notebook 侧参数调整、绘图和结果检查。

## 2. 代码结构

- `src/fea_cpt/base.py`
  作用：定义 `FeatureRecord`、`FeatureParams`、`FeatureContext`、`FeatureResult` 等核心数据结构。
- `src/fea_cpt/io_utils.py`
  作用：读取 `npz` 信号文件，统一生成样本记录，并给出样本类型编码。
- `src/fea_cpt/logging_utils.py`
  作用：生成文件级、函数级执行日志。
- `src/fea_cpt/signal_ops.py`
  作用：完成预处理、包络、STFT、ridge 提取、谐波掩膜、残差重构、小波包分解等公共计算。
- `src/fea_cpt/features.py`
  作用：在共享 `FeatureContext` 上计算全部特征。
- `src/fea_cpt/importance.py`
  作用：提供互信息、随机森林、置换重要性三种排序方法。
- `src/fea_cpt/pipeline.py`
  作用：提供批量计算、保存特征表、保存特征向量映射、范围验证。
- `src/fea_cpt/params.py`
  作用：集中管理默认参数，并为关键参数提供物理意义、默认值、推荐范围和调参依据说明。
- `src/fea_cpt/run_one_sample_validation.py`
  作用：读取 `data` 中一个真实样本，计算全部特征并导出验证结果。
- `notebooks/fea_cpt_feature_demo.ipynb`
  作用：Notebook 入口，用于特征计算、参数调整、绘图、保存和重要性排序。

## 3. 特征覆盖说明

当前实现覆盖了 `特征汇总.md` 中的 9 大类特征：

- 时间/包络类
- 能量/时频类
- 频域/时频熵类
- 谐波/脊线类
- 二倍频/谐波一致性类
- 残差/背景扣除类
- 瞬态/冲击类
- 残差演化类
- 小波/多分辨率类
- 阻尼模型/模型竞争/稀疏表示类

说明：第 57 项 `R_wp,i` 在工程实现中展开为多个固定列，例如 `R_wp_aaaa`、`R_wp_aaad` 等终端节点能量比，因此最终输出特征数大于 65。当前单样本试跑输出为 80 个特征字段，加上 5 个样本元信息字段，共 85 列。

## 4. 共享中间量设计

为减少重复运算，以下中间量只计算一次，并被多个特征复用：

- 去趋势 + 高通 + 主分析带滤波后的 `main_signal`
- `high_signal`、`high2_signal`
- Hilbert 包络 `envelope`
- 鼓包拟合 `envelope_fit`
- 标准 STFT：`stft_freqs`、`stft_times`、`stft_complex`、`stft_power`
- 短窗 STFT：`short_power`
- 主脊线 `ridge_f1`
- 二倍频脊线 `ridge_f2`
- 谐波掩膜 `ridge_mask`
- 残差谱 `residual_power`
- 时域重构 `reconstructed_signal`
- 时域残差 `residual_signal`
- 小波包节点能量 `wavelet_node_energies`

该设计保证新增特征时优先复用上下文，避免重复做 STFT、包络、小波分解等重计算。

## 5. 并行与日志

- 批量接口为 `compute_feature_table_for_paths`。
- 由于当前沙箱环境限制，不允许使用多进程或线程池管道，默认参数 `n_jobs=1`。
- 在普通本地 Python 环境中，可将 `params.py` 中 `N_JOBS` 调整为更大值。
- 日志输出位置：当设置 `log_dir` 时，会在对应目录生成 `fea_cpt_pipeline.log` 和 `fea_cpt_compute.log`。

## 6. 结果保存

调用 `build_feature_dataset(..., output_dir=...)` 或在 Notebook 中显式保存后，会得到：

- `feature_table.csv`：完整特征表
- `feature_vector_mapping.csv`：特征索引与特征名映射
- `feature_validation.csv` 或 `one_sample_feature_validation.csv`：范围验证表
- `logs/*.log`：计算日志
- 绘图 png 文件

其中 `feature_table.csv` 含稳定样本标识字段：

- `sample_id`
- `sample_name`
- `sample_type`
- `sample_type_code`
- `path`

## 8. 当前实现的工程取舍

为了先交付一套可运行、可扩展的源码，以下高级项采用了工程近似实现：

- `Q_MP` 使用 Hankel 低秩重构优度作为矩阵铅笔拟合优度的近似代理。
- `eta_dict` 使用谐波重构分量与阻尼原子分量的 L1 比值作为字典损伤系数比的工程近似。
- `Delta_J` 基于最佳阻尼原子加入前后的误差下降率计算。

如果后续需要更贴近论文级实现，可以在此框架上继续替换这三类函数，而无需改动上层接口。

## 9. 后续建议

- 用 2 类及以上真实样本批量跑特征表，检查类间可分性。
- 在建模前对全部特征做标准化、缺失处理和相关性筛选。
- 若需要更强的 ridge 稳定性，可把动态规划 ridge 替换为更严格的约束优化版本。
- 若需要更精确的阻尼参数估计，可把 `Q_MP` 替换为真正的矩阵铅笔参数恢复实现。
