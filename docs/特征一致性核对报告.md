# PCCP 特征三方一致性核对报告

> 核对对象：
> ① `docs/chatgpt-特征汇总.md`（下称 **汇总**）
> ② `docs/PCCP特征字典.md`（下称 **字典**）
> ③ 代码实现 `src/fea_cpt_gpu_v2_2/features.py`（下称 **代码**，由 `DATA09_v0-flow_feature_extraction.ipynb` 实际调用）
>
> 核对结论先行：
> - 两份文档条目数一致（均 65 行），变量名与排列顺序完全一致，无遗漏、无多余；
> - 两份文档之间有 **6 处实质性冲突**、若干处名称/符号细微差异；
> - 文档与代码之间有 **1 个疑似代码 bug**（`T_half_high`）、**1 个退化特征**（`rho_r` 恒为 1）、约 10 处口径不一致；

### 2.1 代码疑似 bug（建议改代码）

### 2.3 口径不一致的裁决（结合计算原理与物理意义）

> 依据说明：谱通量的标准定义与半波整流见 [Wikipedia: Spectral flux](https://en.wikipedia.org/wiki/Spectral_flux) 与 [FMP Notebooks: Spectral-Based Novelty](https://www.audiolabs-erlangen.de/resources/MIR/FMP/C6/C6S1_NoveltySpectral.html)；谱峭度的标准定义（四阶累积量 / 经典估计器 $\langle|X|^4\rangle/\langle|X|^2\rangle^2-2$）见 [Antoni 2006, MSSP](https://www.sciencedirect.com/science/article/abs/pii/S0888327004001517)；AE 信号上升时间/持续时间/计数等标准事件特征见 [NDE-Ed: AE Signal Features](https://www.nde-ed.org/NDETechniques/AcousticEmission/AE_SignalFeatures.xhtml)；断丝 AE 信号的典型判别特征（短上升时间、长持续时间、高峭度、谱质心等）见 [Multi-angle feature extraction for wire break identification (MDPI)](https://www.mdpi.com/2227-7390/10/19/3690)、[AI-Driven AE Classification for PCCP Wire Break Detection (ASCE)](https://ascelibrary.org/doi/10.1061/9780784487105.024)。

| 特征 | 原理/物理依据 | 裁决：谁不对 | 修改建议（从特征提取角度） |
|---|---|---|---|
| `F_peak` | 谱通量的标准定义是对**每个频点**的功率增量做半波整流再求和：只累计"能量上升"的频点，抑制能量下降与此消彼长的频点间抵消；这是瞬态起始（onset）检测的标准新颖度函数 | **代码错**（先求和后取正：低频降、高频升的突变会被抵消为小值，恰恰漏检断丝类宽带瞬态）；两文档一致且正确 | 改代码为 `np.sum(np.diff(P, axis=1), where>0 逐点取正)`；同时首帧通量置 0（`prepend` 用首帧自身而非 0），消除边界假峰 |
| `SK_max` | Antoni 的谱峭度是各频点的归一化四阶累积量 $C_{4x}/\lvert S_{2x}\rvert^2$，STFT 帧上经典估计为 $\langle\lvert X\rvert^4\rangle/\langle\lvert X\rvert^2\rangle^2-2$；对高斯过程为 0、瞬态频带显著为正，用于定位瞬态主导频带 | **代码错**（代码算的是"各频点**功率**随时间的四阶矩"，无 −2 项、输入是功率而非幅谱，不满足高斯→0 的基准性质，数值无可解释的物理范围）；汇总公式接近经典，方向正确 | 改代码为经典估计器：对短窗 STFT 的复谱按帧计算 $\langle\lvert X_m(k)\rvert^4\rangle/\langle\lvert X_m(k)\rvert^2\rangle^2-2$，再取频点最大 |
| `T_half_high` | "半衰期"是衰减**时长**，AE/超声领域衰减速率是区分源类型的核心量；绝对时刻会把"事件在窗口中的位置"混入特征，跨窗口径不可比 | **代码错**（漏减峰值时刻） | 改代码为 `(below[0] - high_peak) / fs`；从未跌破半值时返回 NaN 或窗口时长，不用 0.0（与真实短半衰期混淆） |
| `rho_r` / `rho_up` / `rho_down` 分母 | "脊线连续率"的物理前提是脊线**可能中断**（噪声帧、谐波结构消失帧）；DP 脊线是全局最优路径，只要搜索带有数据必返回路径，"无效帧"必须额外定义 | **代码错**（缺少有效性判据，特征退化为常数） | 定义有效帧：如"该帧主带能量 > λ×全窗帧能量中位数"（λ≈0.2）或"该帧脊线处功率 > λ×谱中位数"；无效帧 `ridge_f1` 置 0 后，`rho_r`、`H2_ratio`、`epsilon_2x`、`C_h`、`rho_up/down` 全部按有效帧统计，一套判据修复 6 个特征 |
| `G_gap` | "间隙/中断"应是脊线**消失或跳变**，而不是"频率逐位不变"；1e-12 阈值在工程上等价于只统计"卡在同一频点的停顿帧" | **代码判据错**（阈值退化为同 bin 判据）；分母也应统一为 $L_{all}$ | 改代码：间隙 = 有效帧序列中"脊线丢失帧"或"$\lvert\Delta f_1\rvert$ > 频率分辨率×2"的帧；分母用总帧数 |
| `N_turn` | 拐点计数应在方向变化的支撑集上统计，零斜率段不是独立方向 | **代码错**（+→0→− 计 2 次） | 改代码：先剔除 `dfdt==0` 的样本再做 `diff(sign)` |
| `beta_H`、`alpha_hat` | 二者物理含义都是**衰减速率**（高频能量衰减 / 残差包络指数衰减）。对数包络全窗线性拟合时，上升段（斜率为正且大）与衰减段混在一个最小二乘解里，斜率被上升段主导污染——断丝"快起慢衰"的信号恰好上升段最陡，衰减信息反而被淹没 | **代码错**（全窗拟合违背特征物理含义）；文档公式未指明拟合区间，也算欠严谨 | 改代码：拟合窗取"峰值 → 包络跌破峰值 10%（或事件终点）"的峰后段；文档公式补注 $t\in[t_p, t_{off}]$。这一修改同时提升 `beta_H`、`alpha_hat` 的类间区分度 |

| `R_fb` 边界 | AE 事件特征的惯例是以事件边界（阈值/能量分位点）为界的"事件窗"统计（rise time、duration 均如此）；整窗口径会把事件前后的背景噪声计入，30 ms 窗内背景占比高时稀释事件本身的前后不对称性 | **汇总文档错**（整窗口径）；代码与字典精神一致 | 保留代码事件窗口径；修订汇总 5.1.7 公式为 $E_{\text{before}}=\sum_{n_{on}}^{n_p}$、$E_{\text{after}}=\sum_{n_p}^{n_{off}}$；顺手把峰值样本重叠 1 个样本的问题修掉 |

## 三、最终结论与修改清单

### 3.1 结论

1. **覆盖完整性**：两份文档 65 项与代码 64 静态 + `R_wp_*` 族一一对应，无遗漏、无多余，覆盖没有问题。
2. **自洽性**：51/65 项名称-含义-公式自洽；14 项存在错位或原理缺陷（1.4 节），其中 6 项是名称错位、8 项是公式/实现与原理不符。
3. **重复特征**：`R_h ≡ R_2_1`、`Ridge_coh ≡ R_harm` 两组完全同值，均源于"为不同物理意图起了名，但代码未实现区分"。
4. **错误归属**：以信号处理标准定义和 AE 领域惯例为准——`F_peak`、`SK_max`、`T_half_high`、`rho_r` 系判据、`G_gap`、`N_turn`、`beta_H`/`alpha_hat` 拟合窗、`R_h` 区分、`C_f` 归一化、`R_fb` 事件窗是**代码或文档实现侧**的问题；`K_loc` 命名、`Q_MP` 描述、`D_WPT` 公式、`H_stack` 符号笔误是**汇总文档**的问题；`eta_bw`/`Ridge_coh`/`I_burst`/`eta_dict` 命名、频带体系说明、模块路径是**字典**欠完整。

### 3.2 修改清单
