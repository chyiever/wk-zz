## 1. 结论摘要

当前实现中，“多进程并行”本身不是特征值失真的主要来源；真正会改变特征定义和数值的，是为了加速而引入的 **跨频带 STFT 共享方式、CPU/GPU 后端不统一、精度类型变化以及错误恢复策略**。

按严重程度，结论如下。

1. **阻断级 S0**：默认 `ENABLE_SHARED_STFT=True` 路径与关闭共享后的标准路径并非计算同一个信号。共享路径的 STFT 来自外层预处理信号，时域与 WPT 特征却来自窗口内再次高通、稳健归一化和带通后的 `main_signal`。这会系统性改变谱、脊线、谐波、重构和残差特征。
2. **阻断级 S0**：共享路径把全频 STFT 总能量作为分母，却把当前频带残差作为分子，导致 `E_res = E_total - E_harm` 不成立，`rho_res`、`R_harm`、`R_high_res` 等不再具有文档规定的数学含义。
3. **阻断级 S0**：当前窄频带的二倍频搜索区间大多落在当前 STFT 裁剪范围之外。20–30、30–40、40–60 kHz 等频带的 `f2`、`H2_ratio`、`R_2_1`、`R_h` 等结构性失效。
4. **阻断级 S0**：CUDA 使用 Torch STFT，但重构无条件使用 SciPy ISTFT；两者的幅值标度、补边和时间原点不同，不能构成严格的正逆变换对。CUDA 环境下全部时域残差/重构特征存在严重风险。
5. **阻断级 S0**：窗口内部异常会被 worker 捕获并返回只有元数据的行，但源文件仍可能写入 `processed_source_files.txt` 并计为已处理，造成“数据缺列但断点续跑永久跳过”的静默完整性问题。
6. **严重级 S1**：已知有效信号从 100 Hz 开始，但当前外层预处理为 1–95 kHz，窗口内部又固定高通 1 kHz，100 Hz–1 kHz 信息被直接删除；1–100 kHz 特征的 95–100 kHz 又已被外层滤波衰减。
7. **严重级 S1**：1 MHz 下现用标准 STFT 的频率分辨率约 976.6 Hz，短窗 STFT 约 1953.1 Hz，不适合分析 100 Hz–1 kHz；低频和高频应使用不同采样率/窗长的多分辨率方案。
8. **严重级 S1**：残差功率谱与时域残差信号由两种不严格等价的方式生成，导致同一“残差特征族”混用不同残差对象。
9. **严重级 S1**：阻尼原子固定从窗口起点开始且只有余弦相位，不能稳定匹配发生在窗口任意位置、任意相位的断丝衰减振荡。
10. **中等级 S2**：共享批处理把信号和功率转为 `float32`，CUDA Hankel SVD 也使用 `float32`，而 CPU SVD 使用 `float64`。由于高频能量较弱，谱相减、对数、极值和弱能量比可能放大精度差异。
11. **中等级 S2**：`rho_up/rho_down` 用 Hz/s 的斜率和 Hz 单位的 DP 跳变惩罚参数比较，量纲不一致；`D_WPT` 的节点中心频率映射和低频分辨率也不正确。
12. **冗余级 S3**：`A_env = 1 - 2r_p`，`Ridge_coh = R_harm`；在统一能量口径下 `rho_res = 1 - R_harm`；16 个 `R_wp_*` 之和恒为 1。重复计算全部频带、全部 80 个特征会显著增加成本和模型共线性，却不增加信息。

因此，在完成 S0/S1 整改和一致性验收之前，不建议把默认共享/GPU流水线生成的时频、谐波、重构及残差特征作为最终训练基线；已用该路径生成的数据应在修复后重算受影响列。

## 2. 核对前提与当前计算尺度

### 2.1 采样率、窗口和频率分辨率

当前 notebook 参数为：

- 目标采样率：1 MHz；
- 窗口长度：30 ms，即 30,000 点；
- 窗口重叠：0%；
- 标准 STFT 窗：0.64 ms，即 640 点，自动取 `nfft=1024`；
- 短窗 STFT：0.32 ms，即 320 点，自动取 `nfft=512`。

对应频率 bin 间隔为：

\[
\Delta f_{standard}=\frac{10^6}{1024}=976.5625\ \mathrm{Hz}
\]

\[
\Delta f_{short}=\frac{10^6}{512}=1953.125\ \mathrm{Hz}
\]

这意味着：

- 100 Hz–1 kHz 只有约 1 个标准 STFT 有效 bin，短窗 STFT 甚至无法分辨该频段内部结构；
- 每个 10 kHz 窄带只有约 10 个标准 STFT bin；
- 高频瞬态的时间分辨率尚可，但低频谱质心、低频脊线、低频谱熵及低频高低能量比缺乏足够的频率分辨率；
- 不能仅通过把采样率保持在 1 MHz 来提高低频分析精度，低频精度由观察时长和 `nfft`/窗长决定。

### 2.2 1 MHz 对 60 kHz 上限并非必要条件

根据 Nyquist 条件，覆盖 60 kHz 至少需要采样率高于 120 kHz。考虑抗混叠滤波过渡带，工程上使用 200–250 kHz 已足以稳定覆盖 60 kHz：

- 仅当前 1 MHz 数据：建议在完成 60–70 kHz 抗混叠低通后降采样到 250 kHz，恰好 4:1；
- 需要兼容历史 200/500 kHz 数据：建议统一到 200 kHz，Nyquist 为 100 kHz，仍为 60 kHz 留出过渡带；
- 如需研究微秒级到达时刻、原始尖峰或阵列定位，可另保留 1 MHz 原始时域通道，但不必让全部频谱、WPT 和 Hankel 特征都在 1 MHz 上重复计算。

升采样到 1 MHz 不会创造原采样率 Nyquist 以上的新信息，却会成倍增加 STFT、WPT、Hankel SVD、共享内存和多进程复制成本。跨原始采样率可比性应依靠统一的物理滤波、统一的分析采样率和后端一致性，而不是单纯升采样到最高采样率。

### 2.3 高频较弱对计算策略的影响

断丝和环境干扰均随频率升高而衰减时，原始高频绝对能量本身未必具有强区分力，且更容易受以下因素支配：

- 传感器与前端频响滚降；
- 抗混叠滤波器；
- 传播距离和管体衰减；
- 通道增益、安装耦合；
- 环境噪声底；
- `float32`、固定绝对 `eps` 和谱相减的相对误差。

因此，高频特征应优先采用：

- 相对带能量或低/高频对数能量差；
- 相对事件前背景的 SNR/超额能量；
- 峰后对数衰减斜率；
- 谱峭度、谱通量等瞬态结构；
- 带有最低有效能量/SNR 门限的脊线与谐波指标。

不应把未经频响校正的 30–60 kHz 绝对能量直接解释成断丝强度，也不应在高频能量低于噪声门限时继续输出貌似有效的 `f2`、谱质心和比值。

## 3. 严重程度定义

| 等级 | 定义 | 对已有数据的处置 |
|---|---|---|
| S0 阻断 | 改变特征数学定义、导致错误分子/分母、后端结果不等价或静默丢失窗口 | 修复前停止作为最终训练基线；修复后必须重算 |
| S1 严重 | 明显删除已知有效频段、使一类特征结构性退化，或使物理含义不成立 | 优先修复；相关特征需重算或停用 |
| S2 中等 | 数值精度、鲁棒性、可重复性或边界条件问题，通常不会让全部样本都错误 | 增加门限与回归测试；评估后决定重算范围 |
| S3 一般 | 冗余、命名、文档或效率问题，不一定改变现有数值 | 可在版本升级中清理，但应避免进入最终模型 |

## 4. 并行、GPU 与过程量共享专项风险

### 4.1 S0：跨频带共享 STFT 改变了被分析信号

#### 当前实现

非共享路径每个频带按以下顺序计算：

\[
x_w
\rightarrow \text{窗口内高通}
\rightarrow \text{MAD归一化}
\rightarrow \text{当前频带Butterworth带通}
\rightarrow s_B
\rightarrow \operatorname{STFT}(s_B)
\]

共享路径则是：

\[
x_{outer}\rightarrow \operatorname{STFT}(x_{outer})
\rightarrow \text{频率轴裁剪到 }B
\]

但同一上下文中的包络、TKEO、峭度和 WPT 仍由窗口内处理后的 `s_B` 计算。裁剪宽带 STFT 与对 Butterworth 带通信号做 STFT 并不严格相同；更严重的是共享 STFT 还绕过了窗口内 MAD 归一化。

结果是同一频带上下文同时包含两个幅值尺度和两个滤波口径。`epsilon_rec` 甚至用从未归一化共享频谱重构的信号去拟合归一化后的 `main_signal`。

#### 已验证的影响

使用 1 MHz、30 ms 合成信号，在 CPU 上对共享与非共享路径做 A/B 测试，`b_1k_10k` 的代表性结果为：

| 特征 | 共享路径 | 非共享路径 | 判断 |
|---|---:|---:|---|
| `SF` | 0.139506 | 0.000196551 | 约 710 倍差异 |
| `R_2_1` | 0.0000876 | 1.04556 | 物理结论相反 |
| `R_harm` | 0.648678 | 0.975676 | 明显改变 |
| `E_harm` | 19.1785 | 836.574 | 尺度不同 |
| `E_res` | 0.052887 | 20.8563 | 尺度不同 |
| `epsilon_rec` | 0.727883 | 0.020414 | 重构结论失真 |
| `F_peak` | 0.183155 | 5.75121 | 约 31 倍差异 |

这不是可接受的 GPU/CPU舍入误差，而是两条路径计算定义不同。

#### 解决方案

建立唯一的 `BandFeatureContext` 规范：

1. 在整段源文件上完成去均值、100 Hz–60 kHz 保真预滤波和必要的降采样；
2. 在整段源文件上按分析频带预先生成带通信号，避免每个 30 ms 窗口独立 `filtfilt` 的边缘畸变；
3. 每个频带的窗口、包络、STFT、WPT、脊线和残差必须由同一个带通信号切片派生；
4. 可以批量共享 GPU 调用和只读内存，但不能用“宽带 STFT 直接裁剪”冒充“带通信号的 STFT”，除非正式把频域裁剪定义为新的唯一带通方法，并让 CPU基准也完全采用同一定义；
5. 更安全的 GPU 优化是把已经生成的多个频带窗口按 `(band, window, sample)` 堆叠后批量 STFT；同一 STFT 参数组可一起执行，不同多分辨率组分别执行。

### 4.2 S0：共享路径的能量范围混用

共享路径当前使用：

- `total_energy_tf`：共享全频轴功率和；
- `harmonic_energy`：共享全频轴中脊线掩模功率和；
- `residual_power`：当前频带裁剪后的残差功率。

于是：

\[
E_{res,B}\ne E_{total,full}-E_{harm,full}
\]

但 `rho_res` 又计算为：

\[
\rho_{res}=\frac{E_{res,B}}{E_{total,full}}
\]

这不是文档所定义的当前频带残差比例，也不是全频残差比例。

#### 解决方案

推荐所有频带比例使用严格带内定义：

\[
E_{total,B}=\sum_{t,f\in B}P_B(t,f)
\]

\[
E_{harm,B}=\sum_{t,f\in B}M_B(t,f)P_B(t,f)
\]

\[
E_{res,B}=\sum_{t,f\in B}(1-M_B(t,f))P_B(t,f)
\]

并在单元测试中强制：

\[
|E_{total,B}-E_{harm,B}-E_{res,B}|\le \epsilon_E
\]

如果另需全频比例，应使用不同列名，如 `rho_res_global`，不能复用同一个变量名。

### 4.3 S0：CPU/CUDA STFT 与 ISTFT 不等价

CUDA 路径使用 `torch.stft(center=True, pad_mode='reflect', normalized=False)`，CPU 路径使用 `scipy.signal.stft(boundary='zeros', padded=True)`，重构统一使用 `scipy.signal.istft`。风险包括：

- Torch 未归一化 FFT 与 SciPy spectrum scaling 幅值不同；
- reflect 与 zeros 补边不同；
- CUDA 时间轴额外加了 `nperseg/2`，与 `center=True` 的原点不匹配；
- Torch 正变换与 SciPy 逆变换不是配对实现；
- 绝对能量、谱通量、重构误差和所有时域残差特征随后端改变。

#### 解决方案

选择以下一种，不要混合：

- CPU基准：SciPy STFT + SciPy ISTFT；
- GPU生产：Torch STFT + Torch ISTFT，正逆变换完全使用相同的 `n_fft`、`hop_length`、`win_length`、window、center、padding 和 normalization；
- 如必须跨库，显式推导并验证窗函数与 FFT 标度，且全 1 掩模重构误差必须通过验收。

CUDA 时间轴在 `center=True` 下建议使用：

\[
t_m=\frac{m\cdot hop}{f_s}
\]

或者直接依据所选后端的正式帧中心定义生成，CPU与GPU必须完全一致。

### 4.4 S2：`float32` 对弱高频特征的风险

批量路径把窗口转为 `float32`，Torch 生成 `complex64/float32` STFT，残差功率也显式复制为 `float32`；`Q_MP` 的 CUDA SVD 为 `float32`，CPU NumPy SVD 为 `float64`。

单纯使用 `float32` 通常不是错误，但在本项目中高频能量较弱，会放大以下问题：

- 强低频与弱高频同时 FFT 时的动态范围损失；
- `P_res=P-P_harm` 或掩模边界处的相对误差；
- `log(E+eps)` 在弱能量区域的斜率变化；
- `max/median`、谱峭度和高低频比对小分母敏感；
- 近低秩 Hankel 矩阵奇异值在 CPU/GPU 上产生不同截断结果。

#### 解决方案

- 保留原始/滤波信号至少为 `float64` 参考口径；
- GPU STFT 可以使用 `float32/complex64` 提速，但能量累加、均值、方差、熵和比值分母使用 `float64`；
- `eps` 不应只用固定绝对值，应结合当前功率尺度，例如 `eps_rel * median_positive_power`；
- `Q_MP` 对生产数据可继续 float32，但必须与 CPU float64 参考比较，并对低能量或病态矩阵设置质量门限；
- 将 `backend`、`dtype` 和算法版本写入输出元数据，禁止不同后端数据无标记混合。

### 4.5 S0：异常窗口可能被标记为“文件已处理”

worker 内部捕获异常后返回空特征字典和错误文本；外层仍得到包含元数据的 `df_features`，只要 DataFrame 非空就会把源文件写入 processed log。外层 `stats['failed']` 也不一定增加，因为异常已在 worker 内吞掉。

风险是：

- CSV 中存在只有元数据、缺少全部特征的窗口；
- 文件被记录为处理成功；
- 断点续跑永久跳过该文件；
- 汇总只检查部分 NaN 时可能漏掉整行缺列或 CSV schema 漂移。

#### 解决方案

只有同时满足以下条件才写 processed log：

1. 输出窗口数等于预期窗口数；
2. 每个窗口均包含当前 schema 的全部必需特征；
3. 没有非预期 NaN/Inf；允许 NaN 的特征必须在白名单中并有质量原因；
4. worker 错误计数为 0；
5. CSV 写入成功并完成校验。

失败文件应写入独立 retry log，不得进入 processed log。

### 4.6 并行执行本身的风险边界

当前进程池按窗口独立计算，结果回收后按 `window_id` 排序；只要输入数组不可变、窗口与 STFT 索引一一对应，进程完成顺序不会改变特征值。因此“4 个 worker”本身通常只影响吞吐，不改变数学结果。

仍需控制的工程风险包括：

- NumPy/SciPy/PyTorch 内部线程与多进程叠加导致 BLAS 过度订阅；
- 共享内存、下一文件预加载、GPU batch 和 worker 局部矩阵同时存在导致页面文件压力；
- worker 缓存的共享内存句柄长期不释放；
- GPU SVD/归约在不同驱动和算法下存在小幅非确定性；
- `float32` 批量路径与 `float64` 单窗口路径不一致。

建议设置每个 worker 的 BLAS/OpenMP线程数为 1，把 GPU STFT 留在主进程；并行验收以“1 worker 与 N workers 特征逐列一致”为准，而不是只检查是否能完成。

## 5. 特征计算中的结构性问题

### 5.1 S0：窄频带无法计算跨带二倍频

当前二倍频搜索可能在主频带之外。例如 20–30 kHz 内的基频，其二倍频位于 40–60 kHz。将 STFT 先裁成 20–30 kHz 后，不可能从中提取 40–60 kHz 的二倍频。

因此，谐波特征不应机械地在每个孤立窄带上重复。推荐定义一个独立的谐波上下文：

\[
f_1(t)\in[1,30]\ \mathrm{kHz}
\]

\[
f_2(t)\in[2f_1(t)-\Delta f,\ 2f_1(t)+\Delta f]\cap[0.1,60]\ \mathrm{kHz}
\]

其中 `f1` 可以按低频候选带分段搜索，但 `f2` 和能量积分必须读取同一个 100 Hz–60 kHz 规范全频 STFT。高于 30 kHz 的成分没有 60 kHz 以内可观测的二倍频，不应继续输出二倍频一致性特征。

### 5.2 S1：当前有效帧门限对平稳噪声仍过宽

`rho_r` 使用 `frame_energy > 0.2 × median(frame_energy)`。阈值低于中位数，平稳正能量噪声的大部分帧也会被判为有效；同时 `f2` 没有独立的显著性门限。

建议有效脊线同时满足：

- 当前帧带内能量超过事件前/邻近背景的分位数门限；
- 脊线邻域功率相对该帧谱中位数达到最小 SNR；
- 局部峰显著性达到门限；
- `f2` 有独立 active mask；
- 低于高频噪声底时，`H2_ratio/R_2_1/C_h` 返回 NaN 并记录“不可观测”，而不是返回 0 冒充“无二倍频”。

### 5.3 S2：`rho_up/rho_down` 量纲错误

代码计算 `df/dt`，单位是 Hz/s，却与 `ridge_jump_penalty_hz`（Hz）比较。应新增 `ridge_slope_threshold_hz_per_s`，或者直接按相邻帧 `df` 与 Hz 门限比较。文档分母也应写成“相邻两帧均有效的斜率对数量”，而不是 `N_active`。

### 5.4 S2：`H_stack` 可能重复计能

代码分别累加 1、2、3 倍频邻域；邻域重叠时同一时频单元会重复计数，`H_stack` 可能大于 1。若名称保持“能量占比”，应先构造谐波邻域并集掩模再求能量，使结果限制在 `[0,1]`。

### 5.5 S1：残差对象不统一

功率残差使用 `P(1-M)`，时域残差使用 `x - ISTFT(XM)`。二者在非一致 STFT、边界和共享路径下并不严格对应。建议以时域残差为唯一规范对象，再重新计算 `STFT(x_res)`，使时域和频域残差特征来自同一个信号。

### 5.6 S1：阻尼原子没有事件起点与相位

当前原子固定为 `exp(-t/tau) * cos(2πft)`，从窗口 `t=0` 开始。30 ms 无重叠窗口中的事件可以出现在任意位置；当事件位于窗口中后段时，短衰减原子已衰减至接近零。只有余弦原子也无法匹配任意相位。

建议使用：

\[
g(t;t_0,f,\tau,\phi)=u(t-t_0)e^{-(t-t_0)/\tau}\cos(2\pi f(t-t_0)+\phi)
\]

低成本实现可将 `t0` 对齐残差包络峰值/事件起点，并使用正弦、余弦正交投影消除相位依赖。

### 5.7 S2：WPT 频率映射与分辨率不适配

PyWavelets `order='freq'` 的节点路径具有频率翻转关系，当前 `_node_center_hz()` 按每个 `a/d` 直接二分频率轴，会给部分节点分配错误中心频率。应按 `get_level(..., order='freq')` 返回索引计算中心频率。

此外，1 MHz、level=4 时每个节点宽 31.25 kHz，最低中心为 15.625 kHz。对 100 Hz–1 kHz、1–5 kHz、1–10 kHz 等频带，所有节点都可能被分到“高频”侧，使 `D_WPT≈1`。WPT 应在按频带降采样后的信号上计算，或显著提高分解层级；不建议在每个窄带上机械重复当前 level=4 WPT。

### 5.8 S3：严格冗余

- `A_env = 1 - 2r_p`，二者严格线性重复；
- `Ridge_coh = R_harm`，代码直接同值；
- 能量口径统一后，`rho_res = 1 - R_harm`；
- 16 个 `R_wp_*` 之和恒为 1；
- `Delta_J` 是 `C_damp²` 与时域残差相对能量的确定性组合。

建议在正式 schema 中停用 `A_env`、`Ridge_coh`，并在 `rho_res/R_harm` 中保留一个；WPT 节点保留 15 个或使用对数比表示。这样可以降低列数、计算量和模型共线性。

## 6. 预处理设计建议

### 6.1 建议的规范预处理链

推荐按“整文件预处理—多采样率/多频带派生—窗口切片—特征计算”组织：

1. 读取原始信号及真实采样率；
2. 检查削顶、NaN、常数段、时间戳和通道；
3. 在整文件上去直流/慢漂移；
4. 使用 SOS 滤波器保真保留 100 Hz–60 kHz，简单 Butterworth 截止点可先取约 80 Hz 和 65 kHz，为目标通带边界留过渡余量；更严格时应明确 passband/stopband 指标后设计；
5. 根据特征族生成 200/250 kHz 高频分析信号和 10/20/50 kHz 低中频分析信号；所有降采样前必须抗混叠；
6. 在整文件上生成各带通信号，再切 30 ms 窗，避免对每个窗口单独 `filtfilt` 的边缘伪影；
7. 计算公共增益口径的能量特征；另建可选的形状归一化信号计算包络、峭度等特征；
8. 所有参数、滤波器系数、采样率、dtype、CPU/GPU后端和 schema 版本写入输出元数据。

### 6.2 不建议继续固定窗口内 1 kHz 高通

当前 `build_params_for_band()` 对所有频带固定 `highpass_hz=1000`。既然已知信号下限为 100 Hz，则该操作会使 `b_1k_*` 以下的信息不可恢复，也使未来新增 `b_100_1k` 频带名存实亡。

建议：

- 外层整文件预滤波已完成时，窗口内部不再重复高通；
- 如必须保留，每个频带的高通截止应低于目标频带下界并留过渡区；
- 100 Hz–1 kHz 特征必须使用专门的低频信号路径，不得复用 1 kHz 高通路径。

### 6.3 能量特征与形状特征应分开归一化

高频天然较弱时，如果每个频带分别归一化，再比较频带能量，就会人为抹掉真实的谱衰减。建议区分：

- **能量路径**：各频带保持共同通道增益和统一标定，只做全局尺度归一化，保留跨频带能量关系；
- **形状路径**：允许在当前频带内做 RMS/MAD 归一化，用于包络形状、峭度、对称性、谱熵等增益不变特征；
- 列名明确标注 `energy_calibrated`、`shape_normalized` 或在 schema 元数据中记录口径。

### 6.4 建议引入背景校正

由于环境干扰也随频率升高而衰减，仅观察事件的原始频谱斜率不足以区分断丝和环境。建议从事件前窗口或邻近无事件窗口估计背景：

\[
SNR_B=10\log_{10}\frac{E_{event,B}+\epsilon}{E_{background,B}+\epsilon}
\]

或：

\[
E_{excess,B}=\max(E_{event,B}-\operatorname{median}(E_{background,B}),0)
\]

高频脊线、谐波和衰减特征只有在相应频带 `SNR_B` 超过门限时才有效。这样能避免“高频很弱”与“高频根本不可观测”混为一谈。

## 7. 推荐频带方案

### 7.1 核心原则：按特征族分配频带，不在每带重复全部 80 项

当前 8 个频带为：1–100、1–10、10–20、20–30、30–40、40–60、10–50、1–50 kHz。主要问题是：

- 1–100 kHz 超出已知 60 kHz 有效上限，且外层预滤波只到 95 kHz；
- 1–50、10–50 与多个窄带高度重叠；
- 100 Hz–1 kHz 完全缺失；
- 对 20–30、30–40、40–60 kHz 重复计算二倍频特征没有物理可观测范围；
- 在所有带上重复 WPT、Hankel SVD、阻尼原子和全部残差特征，成本高且产生大量冗余/退化列。

### 7.2 推荐的 7 个基础频带

建议先以以下 7 个频带作为候选，之后用训练集内嵌套交叉验证和稳定性分析做删减：

| 建议列名前缀 | 频带 | 主要用途 | 是否计算全部特征 |
|---|---:|---|---|
| `b_100_60k` | 0.1–60 kHz | 全有效带事件总览、跨带能量、全谱残差 | 否；只算全带适用特征 |
| `b_1k_60k` | 1–60 kHz | 对低频环境扰动较稳健的主分析带 | 可作为主要全量候选，但谐波需独立上下文 |
| `b_100_1k` | 0.1–1 kHz | 低频结构响应与环境基线 | 只算低频能量/谱形/慢包络，不算快速脊线 |
| `b_1k_5k` | 1–5 kHz | 低中频主体、低阶结构模态 | 低中频特征子集 |
| `b_5k_15k` | 5–15 kHz | 常见主能量与候选基频区 | 包络、谱形、基频脊线；二倍频从全谱读取 |
| `b_15k_30k` | 15–30 kHz | 中高频瞬态和可能的二倍频区 | 高频瞬态/衰减/残差；谨慎计算 f1 |
| `b_30k_60k` | 30–60 kHz | 弱高频冲击、传播衰减和高频残差 | 只算有SNR门限的瞬态/衰减/能量特征 |

这组边界近似按对数尺度展开，符合频率越高能量越弱的特点；30–60 kHz 保持较宽频带，以积累足够能量，不再拆成 30–40 和 40–60 两个都很弱的带作为默认配置。

如果必须维持恰好 8 个频带，可增加 `b_5k_30k` 作为基频/主体结构宽带，但不要再增加 60 kHz 以上频带。`b_5k_30k` 的二倍频仍应从 0.1–60 kHz 全谱上下文读取。

### 7.3 特征族与频带分配

| 特征族 | 推荐频带 | 不推荐做法 | 说明 |
|---|---|---|---|
| 峰位、能量质心、包络不对称、前后能量比、半衰期 | 0.1–60、1–60；必要时 5–15、15–30、30–60 | 在每个极窄频带全部重复 | 全带描述事件位置，分带描述不同频率衰减 |
| 绝对/相对频带能量、谱质心、谱平坦度、谱熵 | 0.1–1、1–5、5–15、15–30、30–60，加全带 | 使用未经背景校正的弱高频绝对能量作主判据 | 建议增加背景SNR和能量占比 |
| 基频脊线、拱形、上/下降率、转向 | 1–15 或 5–30 kHz，依据真实谱峰调整 | 在 30–60 kHz 弱能量带强制提取主脊线 | 先做SNR/峰显著性门限 |
| 二倍频一致性、`R_2_1`、`R_h`、谐波栈 | `f1` 搜索 1–30 kHz，`f2` 从 0.1–60 kHz 全谱读取 | 在隔离的 20–30、30–40、40–60 kHz STFT 内搜索 `2f1` | 30 kHz以上基频没有可观测的带内二倍频 |
| 高频衰减、谱通量、谱峭度、TKEO | 15–30、30–60，以及 1–60 | 高频SNR不足仍返回0作为有效值 | 高频弱时应返回不可观测/NaN质量码 |
| 谐波重构与残差 | 1–60 或 5–60 的统一全谱上下文 | 每个窄带独立重构再互相比较 | 使用同一STFT/ISTFT后端和能量范围 |
| WPT | 0.1–60、1–60；或各降采样尺度各算一次 | 1 MHz、level=4 在所有窄带重复 | 必须匹配采样率与分解层级 |
| 阻尼原子、Hankel低秩质量 | 1–60 或 5–60 的事件对齐残差 | 每个频带、每个窗口无门限全算 | 计算昂贵，建议只对候选事件或主带计算 |

### 7.4 多分辨率采样/STFT建议

| 分析频段 | 建议分析采样率 | 建议窗长/方法 | 适合特征 |
|---|---:|---|---|
| 100 Hz–1 kHz | 10–20 kHz | 10–20 ms STFT、Welch或整窗谱；30 ms 内不建议做复杂轨迹 | 带能量、谱质心、谱斜率、背景SNR、慢包络 |
| 1–5 kHz | 20–50 kHz | 4–10 ms 窗，显式设置目标频率分辨率 | 能量、谱形、有限的主频轨迹 |
| 5–15 kHz | 50–100 kHz | 1–4 ms 窗 | 包络、主脊线、谐波基频、谱熵 |
| 15–30 kHz | 100–200 kHz | 0.64–2 ms 窗 | 瞬态、二倍频、衰减、残差 |
| 30–60 kHz | 200–250 kHz | 0.32–1 ms 窗 | 高频谱通量、谱峭度、衰减、SNR |

30 ms 窗内最低仅含约 3 个 100 Hz 周期，因此 100 Hz 附近不适合计算帧级上升率、下降率、曲率和转向次数。低频段应以整窗或跨多个窗口的稳健谱统计为主。

## 8. 推荐的新流水线结构

```text
原始源文件（保留真实采样率）
    │
    ├─ 数据质量检查：NaN、削顶、常数段、时间戳、通道
    │
    ├─ 整文件去直流/慢漂移 + 100 Hz–60 kHz 保真预滤波
    │
    ├─ 多采样率派生
    │    ├─ 10/20 kHz：100 Hz–1 kHz
    │    ├─ 50/100 kHz：1–15 kHz
    │    └─ 200/250 kHz：5–60 kHz
    │
    ├─ 整文件按频带生成带通信号（只做一次）
    │
    ├─ 切 30 ms 窗
    │
    ├─ 按相同 STFT 配置分组，GPU 批量计算每个带通信号的 STFT
    │
    ├─ 独立谐波上下文：f1 在低/中频搜索，f2 在全 60 kHz 范围搜索
    │
    ├─ 同后端 STFT/ISTFT 得到唯一残差信号，再计算残差 STFT
    │
    ├─ 特征族按适用频带计算，不再做 80 × 所有频带笛卡尔积
    │
    └─ 完整性、范围、一致性验收通过后写CSV和processed log
```

这一结构仍然可以充分利用并行和 GPU：

- 滤波在整文件上按频带并行；
- 同配置频带/窗口堆叠后做 GPU batch；
- STFT、功率、脊线、掩模在同一上下文内共享；
- WPT/Hankel等 CPU 重任务可在窗口进程中并行；
- 共享内存只共享不可变的规范带通信号和经过验证的同口径过程量。

关键原则是：**共享计算必须是代数上等价的公共子表达式；不能为了少算一次 STFT 而改变被分析信号。**

## 9. 验收与回归测试

### 9.1 建立 CPU float64 正确性基准

先暂时关闭共享 STFT 和 CUDA，使用单进程、CPU、float64、配对的 SciPy STFT/ISTFT 形成 reference。只有参考路径通过解析信号测试后，才允许优化路径上线。

### 9.2 必测一致性项目

1. **worker一致性**：1 worker 与 4 workers 的逐列结果一致；计数型特征完全相同，浮点特征在规定容差内。
2. **batch一致性**：单窗口与批量窗口结果一致。
3. **共享一致性**：启用过程量共享前后，同一规范定义的特征一致；不能只验证列数和无NaN。
4. **CPU/GPU一致性**：归一化/比值特征建议 `rtol≤1e-5`；绝对能量在完成统一标度后建议 `rtol≤1e-4`。
5. **重构一致性**：全1掩模的归一化重构误差建议 CPU `<1e-8`、GPU `<1e-5`，具体阈值可按后端实测收紧。
6. **能量守恒**：同一频带满足 `E_total≈E_harm+E_res`。
7. **频率误差**：解析正弦/线性调频信号的脊线误差不超过 1 个目标 STFT bin。
8. **谐波测试**：构造 `f`、`2f`、无二倍频和二倍频偏移信号，验证 `H2_ratio/R_2_1/epsilon_2x` 单调响应。
9. **弱高频测试**：逐步降低 30–60 kHz 幅值，验证低于SNR门限后输出“不可观测”，而不是随机脊线。
10. **事件平移测试**：同一衰减振荡置于窗口前、中、后，除峰位类特征外，阻尼与衰减特征应保持稳定。
11. **低频测试**：100、300、800 Hz 解析信号验证低频分析路径，不允许复用 1 MHz/0.64 ms STFT得出虚假的高分辨率结论。
12. **重复运行测试**：同一 GPU、不同 batch size、不同 worker 数重复运行，结果漂移不得超过容差。

### 9.3 必测数据完整性项目

- 每文件实际窗口数等于理论窗口数；
- 每窗口列集合等于固定 schema；
- 非预期 NaN/Inf 数为 0；
- 允许 NaN 必须带质量码，如 `insufficient_post_peak_frames`、`h2_unobservable`、`low_snr`；
- 任何窗口失败时，源文件不得进入 processed log；
- 输出记录 `feature_schema_version`、参数哈希、Git commit、backend、dtype、原始/分析采样率和频带配置。

## 10. 分阶段整改方案

### 阶段 A：冻结基线与阻断错误修复

1. 默认关闭 `ENABLE_SHARED_STFT` 和 CUDA，建立 CPU float64 reference；
2. 修复 processed log 的成功判据；
3. 将预处理有效下限恢复到 100 Hz，取消窗口内固定 1 kHz 高通；
4. 删除 60 kHz 以上分析带；
5. 统一能量范围和唯一残差定义；
6. 用同一库完成 STFT/ISTFT；
7. 将谐波上下文从窄频带上下文中拆出。

### 阶段 B：多分辨率与频带重构

1. 实现 100 Hz–1 kHz、1–15 kHz、5–60 kHz 多采样率分析路径；
2. 按第 7 节配置候选频带；
3. 按特征族输出，不再固定每带80列；
4. 增加背景SNR、超额能量和高频可观测性门限；
5. 修复 WPT 节点频率映射和分解尺度；
6. 修复阻尼原子起点与相位。

### 阶段 C：恢复 GPU 与安全共享

1. 实现配对的 Torch STFT/ISTFT；
2. 对已经生成的规范带通信号做跨窗口/跨频带 batch，而不是裁剪未对齐的宽带 STFT；
3. 功率统计和比值使用 float64 累加；
4. 通过 CPU/GPU、单窗/batch、1/N worker 全量回归；
5. 只有全部验收通过，才重新把 GPU/共享设为默认。

### 阶段 D：数据与模型重建

1. 用新 schema 重算 flow、BK、QJ；
2. 不混用旧共享路径 CSV 与新结果；
3. 在训练折内完成频带/特征选择，避免用测试集选频带；
4. 比较全带、分带、背景校正和多分辨率四组消融；
5. 用跨工况、跨文件、跨采集批次验证，而不是随机打散相邻窗口。

## 11. 最终建议

### 11.1 近期可执行的最小安全方案

在代码大改前，如必须尽快获得可解释基线，建议：

- 使用 CPU、单/少进程、`ENABLE_SHARED_STFT=False`；
- 仅使用 1–60、5–15、15–30、30–60 kHz 四个路径做第一版，其中低于1 kHz的信息暂列为“待多分辨率补充”；
- 谐波特征只在 1–60 kHz 全谱上下文中计算，`f1` 限于 1–30 kHz；
- 暂停使用 `E_harm/E_res/rho_res/R_harm/epsilon_rec` 等未完成能量/重构一致性验证的特征；
- 暂停使用每个窄带的 WPT、阻尼原子和 `Q_MP`；
- 保留包络、谱形、谱通量、谱峭度、高频衰减等通过解析测试的特征；
- 对 30–60 kHz 特征增加背景SNR门限。

### 11.2 推荐的正式频带

正式版本建议优先采用：

```python
BANDS = [
    ('b_100_60k',  (100.0,    60_000.0)),
    ('b_1k_60k',   (1_000.0,  60_000.0)),
    ('b_100_1k',   (100.0,     1_000.0)),
    ('b_1k_5k',    (1_000.0,   5_000.0)),
    ('b_5k_15k',   (5_000.0,  15_000.0)),
    ('b_15k_30k',  (15_000.0, 30_000.0)),
    ('b_30k_60k',  (30_000.0, 60_000.0)),
]
```

如必须保持8带，可增加：

```python
('b_5k_30k', (5_000.0, 30_000.0))
```

但这些频带不能继续共用同一套 1 MHz、0.64 ms STFT 参数，也不应全部计算相同的80项特征。低频采用长窗/低采样率谱统计，高频采用短窗瞬态分析，谐波采用跨频带统一上下文，才与已知的 100 Hz–60 kHz 频谱先验相符。

### 11.3 一句话裁决

**并行可以保留，GPU可以保留，过程量也可以共享；但只有在共享对象来自同一个规范信号、CPU/GPU正逆变换和标度完全一致、频带与特征族物理可观测范围匹配，并通过逐列回归测试后，性能优化才不会牺牲最终特征值的精度与准确性。**

### C.3 修复后的数学契约

对频带 $B$，整文件预处理后的信号先经固定带通得到 $x_B$。窗口 $w$ 只做同一窗口 MAD 标度 $a_w$，因此批处理输入为：

\[
s_{B,w}[n]=\frac{x_B[n+n_w]}{a_w}.
\]

GPU 共享仅共享一次批量调用，不改变输入定义：

\[
X_{B,w}=\operatorname{STFT}_{\mathcal L}(s_{B,w}),\qquad
X_{h,B,w}=M_hX_{B,w},\qquad
X_{r,B,w}=(1-M_h)X_{B,w},
\]

\[
x_{h,B,w}=\operatorname{ISTFT}_{\mathcal L}(X_{h,B,w}),\qquad
x_{r,B,w}=\operatorname{ISTFT}_{\mathcal L}(X_{r,B,w}),
\]

其中 $\mathcal L$ 在一个上下文内固定为 SciPy 或 Torch。Torch 生产路径允许 GPU 前向、CPU 逆向，但仍是 Torch 的同一算法和参数约定，不跨库。

统一能量定义为：

\[
E_{total}=\sum_{k,m}|X_{B,w}[k,m]|^2,
\quad E_{harm}=\sum_{k,m}|M_hX_{B,w}[k,m]|^2,
\quad E_{res}=\sum_{k,m}|(1-M_h)X_{B,w}[k,m]|^2.
\]

由于当前 $M_h$ 是二值掩模，在浮点容差内应满足：

\[
E_{total}=E_{harm}+E_{res}.
\]

局部背景量使用事件帧均值而不是全文件类别先验：

\[
SNR_B=10\log_{10}\frac{\bar E_{event,B}+\varepsilon}{\bar E_{background,B}+\varepsilon},
\]

\[
E_{excess,B}=\max\left(\sum_{m\in event}E_B[m]-N_{event}\bar E_{background,B},0\right).
\]

背景帧优先取事件边界之外的帧；若不足窗口的 20%，回退为窗口前 20%。这只是局部可观测性估计，不是分类标签。`high_observable=0` 时 `beta_H/T_half_high` 为 NaN；`H2_observable` 使用二倍频脊线邻域自身的事件/背景 SNR，若为 0，则 `H2_ratio/R_2_1/R_h/epsilon_2x/C_h` 为 NaN。

### C.4 修复后的频带与特征族建议

DATA09 notebook 当前采用下表。这里区分“可以立即计算”和“需多分辨率路径后启用”，避免因 1 MHz、0.64 ms STFT 在低频只有约一个 bin 而制造伪精度。

| 频带 | 当前建议输出 | 用途与限制 |
|---|---|---|
| 100 Hz–60 kHz | time、spectral、ridge、harmonic、residual、background、wavelet、damped | 唯一全带谐波/残差/WPT/阻尼上下文；计算最重，只保留一份 |
| 1–60 kHz | time、spectral、ridge、residual、background | 对照去除极低频后主体结构；不再重复谐波/WPT/阻尼 |
| 100 Hz–1 kHz | time、background | 当前先保留带通信号的包络/形状和局部背景量；谱质心、谱熵、脊线必须等长窗/低采样率组实现后再启用 |
