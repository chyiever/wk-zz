# 断丝识别研究方案

## 第一章 研究背景与目标

### 1.1 研究背景

PCCP 管道断丝信号属于短时瞬态结构响应信号，持续时间通常在 0.01 s 量级，能量主要分布在 5 kHz 到 40 kHz 范围内，表现为一次性突发、大头拖尾、前强后弱的衰减型波形。在低流速条件下，环境噪声相对平稳，断丝信号通常具有较高信噪比，特征较容易观察；但在高流速条件下，信号环境显著复杂化，标准动水噪声呈现鼓包包络、基频漂移以及二倍频结构，断丝信号往往叠加在该类非平稳噪声之上，导致直接识别难度显著增加。

除动水噪声外，外界冲击、锤击、碰撞等干扰也会产生瞬时宽带响应，其时域形态常与断丝信号接近，同样可能表现为大头拖尾和短时衰减，因此容易造成误报。由此，本研究面向的不是简单的二分类问题，而是一个分层次、分场景的断丝识别问题。

### 1.2 信号类型与特点

本研究涉及四类典型信号：

- 低流速下的断丝信号：背景噪声平稳，断丝信号高 SNR，适合提取断丝本征特征。
- 高流速下的断丝信号：背景常包含标准二倍频动水噪声，断丝可能整段叠加、局部叠加，或恰好发生在短暂平稳片段中。
- 高流速下的标准动水噪声：通常呈鼓包型包络，具有局部基频漂移结构，并伴随较明显的二倍频。
- 外界干扰信号：包括锤击、碰撞等冲击类信号，通常也是瞬态宽带响应，易与断丝混淆，且也可能叠加在动水噪声背景上。

### 1.3 重难点分析

本研究的难点主要体现在以下几个方面。

第一，断丝信号与外界冲击信号在低流速环境下具有相似的瞬态属性，仅靠峰值、持续时间、总能量等单一指标难以可靠区分。

第二，标准动水噪声本身不是平稳噪声，而是具有明确结构特征的非平稳信号。其鼓包包络、基频漂移和二倍频结构容易淹没断丝信号的局部特征。

第三，高流速下真正需要判别的是两类混合信号：“二倍频动水噪声 + 断丝”与“二倍频动水噪声 + 冲击等干扰”。这意味着研究重点不是单纯识别瞬态事件，而是在复杂背景中识别出具有断丝物理机理的附加瞬态成分。

第四，样本工况差异、传感器耦合差异、幅值动态范围变化都会影响特征稳定性，因此必须优先考虑与物理机理相对应、且对工况变化相对稳健的相对特征和结构特征。

第五，实际工程中信号窗往往并不严格对应单个完整事件。一个分析窗内可能只截取到半个断丝响应，也可能只覆盖一个鼓包噪声的前半段或后半段，还可能同时包含多个鼓包。因此，许多在完整事件上成立的整体规律在单窗内并不总是清晰可见。例如，标准动水噪声“基频先增大后减小”的完整拱形轨迹，在部分窗或多鼓包窗中可能并不明显。相应地，特征设计必须从“完整事件模板匹配”转向“局部结构统计 + 滑窗聚合”的思路。

### 1.4 研究目标

围绕工程识别流程，本研究的目标分为三个层次。

1. 在低流速平稳背景下，建立断丝信号与平稳环境噪声、锤击等冲击干扰信号的区分方法，提取断丝本征特征。
2. 在高流速环境下，建立标准二倍频动水噪声的识别与排除方法，为混合场景分析提供背景建模基础。
3. 在混合场景中，针对“二倍频动水噪声 + 断丝”和“二倍频动水噪声 + 冲击等干扰”两类信号，建立能够识别出断丝的特征体系与判决流程。

### 1.5 主要思路路线

本研究建议采用“三步识别、逐层收缩”的技术路线。

第一步，在低流速高 SNR 条件下建立断丝本征特征库，重点提取断丝的包络不对称性、频率衰减规律和短时宽带瞬态特征，并与平稳背景噪声、冲击类干扰进行区分。

第二步，在高流速但无断丝、无外界干扰的条件下，建立标准二倍频动水噪声模型，重点提取其鼓包包络、局部基频脊线、二倍频一致性和时频结构有序性特征，实现对标准动水噪声的识别和排除。考虑到分析窗中可能只有部分鼓包或多个鼓包，该模型不强依赖完整的“先升后降”轨迹，而优先使用局部谐波占据率、脊线连续性和局部漂移统计量。

第三步，在高流速混合场景中，先利用标准动水噪声模型解释和扣除可归因于动水噪声的规则结构，再对剩余残差中的局部瞬态成分进行分析，通过残差能量、高频突发、衰减规律和冲击细分特征，区分“动水噪声 + 断丝”与“动水噪声 + 外界干扰”。在实现层面，建议采用多尺度滑窗提取局部特征，再对一个总分析窗中的多个局部结果取最大值、百分位数或计数统计，避免因事件截断导致误判。

整体上，本研究强调“背景建模 + 残差检测 + 物理机理判别”的分层框架，而不建议直接对所有复杂场景信号进行端到端单步分类。

## 第二章 低流速下断丝特征提取

### 2.1 任务定义

本章研究对象为低流速环境下的三类信号：

- 高 SNR 断丝信号；
- 平稳环境噪声；
- 锤击、碰撞等冲击类外界干扰。

本章目标是提取断丝的本征特征，为后续高流速复杂场景识别奠定基础。

### 2.2 研究思路

低流速环境下背景噪声相对平稳，因此断丝识别的主要矛盾是“断丝”与“冲击干扰”的区分，而不是与动水噪声的区分。本章建议围绕以下三个方面提取特征。

1. 包络形态特征：表征断丝信号是否具有前强后弱、快起慢衰的非对称包络。
2. 频率演化特征：表征断丝信号是否具有高频衰减快、谱质心下移明显的衰减规律。
3. 冲击细分特征：在都属于瞬态冲击的前提下，进一步区分断丝与锤击类干扰在高频分布、衰减稳定性和局部尖锐度上的差异。

同时需要注意，实际信号窗未必完整包含一次断丝事件。对于只截取到半个断丝的情况，整窗层面的对称性和完整持续时间会失真。因此，本章推荐采用“主瞬态定位 + 局部窗特征 + 整窗统计聚合”的方法：先定位窗内最强瞬态，再围绕该瞬态提取局部特征；如一个窗内存在多个瞬态候选，则分别计算并取最大值、前百分位数或候选个数作为最终特征。

### 2.3 推荐特征定义

#### 2.3.1 时域与包络特征

对带通信号 x(t) 计算 Hilbert 包络：

$$e(t) = |x(t) + j H\{x(t)\}|$$

其中 H{·} 表示 Hilbert 变换。基于包络，定义以下特征。

1. 峰值位置比例

$$r_{p} = t_{peak} / T$$

其中 t_peak 为包络峰值时刻，T 为局部事件窗长度。断丝信号通常峰值更靠前。

2. 上升时间与下降时间比

$$R_{td} = T_{decay} / T_{rise}$$

其中 T_rise 表示包络从 10% 峰值升至峰值所需时间，T_decay 表示从峰值衰减至 10% 峰值所需时间。断丝一般呈快起慢衰，因此 R_td 往往较大。

3. 前后能量比

$$R_{fb} = E_{before} / E_{after}$$

其中 E_before 为峰值之前的包络能量积分，E_after 为峰值之后的包络能量积分。断丝和平稳噪声、冲击干扰在该指标上常存在明显差异。

4. 包络对称性

$$S_{env} = corr(e(t), e^{rev}(t))$$

其中 e^{rev}(t) 表示时间反转后的包络。断丝包络通常不对称，S_env 相对较低。

5. 包络偏度

$$Sk_{env} = (1 / N) Σ ((e_{i} - μ_{e})^{3} / σ_{e}^{3})$$

偏度可定量描述包络向拖尾方向偏斜的程度。

#### 2.3.2 频域与时频特征

对事件信号进行短时傅里叶变换，得到时频谱 S(t, f)。当分析窗只包含部分事件时，建议对局部活动段分别计算以下特征，并采用最大值或中位数进行聚合。推荐特征如下。

1. 谱质心及其衰减斜率

$$SC(t) = (Σ (f · P(t, f))) / (Σ P(t, f))$$

其中

$$P(t, f) = |S(t, f)|^{2}$$

对 SC(t) 做线性拟合，其斜率 k_sc 反映高频向低频的迁移速度。断丝通常表现为更显著的负斜率。

2. 高频低频能量比

$$R_{hl}(t) = E_{high}(t) / E_{low}(t)$$

其中 E_high(t) 为高频子带能量积分，E_low(t) 为低频子带能量积分。进一步对 R_hl(t) 随时间拟合，可得到高频衰减速率 k_hl。断丝通常具有更快的高频衰减。

3. 时频熵

$$H_{tf} = - Σ p_{ij} ln(p_{ij})$$

其中

$$p_{ij} = P(t_{i}, f_{j}) / (Σ P(t_{i}, f_{j}))$$

时频熵反映能量在时频平面上的离散程度，可用于表征断丝与平稳噪声、冲击类干扰之间的差异。

#### 2.3.3 冲击细分特征

1. TKEO 峰值比

对离散信号 x[n] 计算 Teager-Kaiser 能量算子：

$$Ψ[n] = x[n]^{2} - x[n-1] · x[n+1]$$

定义峰值比：

$$R_{tkeo} = max(Ψ[n]) / mean(Ψ[n])$$

该指标对局部尖锐瞬态较敏感。

2. 局部峭度

$$K = E[(x - μ)^{4}] / σ^{4}$$

可在滑动窗或高频子带上计算局部峭度，用于描述冲击尖锐性。

3. 高频半衰期

设高频子带能量包络为 E_high(t)，定义其从峰值衰减到一半所需时间为 T_half,high。断丝的高频衰减通常更稳定、更短。

#### 2.3.4 小波特征

建议采用小波包分解或连续小波变换，重点关注高频子带。推荐特征包括：

- 小波包各节点能量比；
- 高频子带峭度；
- 高频子带能量突发指数；
- 小波熵。

其中，高频子带能量突发指数可定义为：

$$I_{burst} = max(E_{wp}(t)) / median(E_{wp}(t))$$

### 2.4 推荐特征组合

针对低流速场景，建议优先采用以下组合：

1. 包络对称性 S_env；
2. 上升下降时间比 R_td；
3. 谱质心衰减斜率 k_sc；
4. 高频低频能量比衰减斜率 k_hl；
5. TKEO 峰值比 R_tkeo；
6. 高频子带峭度。

其中，前四项用于刻画断丝的“快起慢衰、高频快速衰减”本征特征，后两项用于抑制外界冲击误报。

### 2.5 实验流程

1. 数据准备：整理低流速下的断丝样本、平稳环境噪声样本和锤击等冲击干扰样本。
2. 预处理：统一采样率，带通滤波，截取固定长度事件窗，并进行幅值归一化。
3. 主瞬态定位：在每个总窗内检测最强瞬态或若干个候选瞬态。
4. 包络分析：围绕局部瞬态计算 Hilbert 包络及其峰值位置、对称性、上升下降时间比等特征。
5. 时频分析：采用 STFT 或 CWT 计算谱质心斜率、高低频能量比斜率、时频熵等特征。
6. 小波分析：对高频子带计算能量突发指数和峭度。
7. 特征聚合：对多个局部窗特征取最大值、中位数、95% 分位数或候选数目。
8. 特征评价：通过散点图、箱线图、Fisher score、AUC 等指标评估可分性。
9. 模型验证：选取少量强特征，采用 LDA 或 SVM 进行交叉验证。

## 第三章 高流速下标准二倍频动水噪声特征提取

### 3.1 任务定义

本章研究对象为高流速条件下、无断丝和无外界干扰时的标准二倍频动水噪声。目标是在复杂背景中识别出这一类“可解释的规则噪声”，以便在后续混合场景中优先排除。

### 3.2 研究思路

标准动水噪声并非随机白噪声，而具有较强规律性。根据已有观测，其主要特征为：

- 时域包络呈鼓包形，两端细、中间粗；
- 时频图中存在清晰的基频脊线；
- 二倍频结构明显；
- 在完整鼓包中，基频随时间常呈先升后降变化，但在实际窗截取条件下，也可能只表现为上升段、下降段，或在一个窗内出现多个局部拱形片段；
- 脊线连续、能量分布相对有序。

因此，本章的核心不是提取“冲击特征”，而是建立“标准动水噪声模板”，即围绕鼓包包络、谐波结构和时频脊线有序性建立特征体系。需要强调的是，该模板应建立在局部统计意义上，而不是强依赖单窗内必须出现完整的鼓包和完整的“先升后降”轨迹。

### 3.3 推荐特征定义

#### 3.3.1 包络与形态特征

仍以 Hilbert 包络 e(t) 为基础，定义：

1. 包络对称性

$$S_{env} = corr(e(t), e^{rev}(t))$$

标准鼓包噪声通常对称性较高。

2. 峰值位置比例

$$r_{p} = t_{peak} / T$$

标准鼓包噪声峰值通常靠近事件中部。

3. 鼓包集中度

设 e_norm(t) 为归一化包络，定义阈值 η 下的有效持续时间为 T_η，则

$$C_{bulge} = T_{η} / T$$

该指标反映鼓包主体在整段信号中的占比。

4. 局部鼓包个数

设包络超过阈值 η 且相邻间隔大于 τ_sep 的局部鼓包数为 N_bulge，则 N_bulge 可反映一个总窗中包含的鼓包个数，用于描述多鼓包背景。

#### 3.3.2 基频与二倍频特征

在时频图上提取主脊线 f_1(t) 以及次脊线 f_2(t)。考虑到单窗中可能只包含部分鼓包或多个鼓包，推荐优先提取对局部结构稳定的统计特征，而不是仅依赖完整弧线拟合。推荐特征如下。

1. 二倍频存在度

$$H2_{ratio} = N\{|f_{2}(t) - 2 f_{1}(t)| < Δf\} / N_{active}$$

其中 N_active 为能量活跃帧数。标准动水噪声的 H2_ratio 通常较高。

2. 谐波能量比

$$R_{h} = E_{2nd} / E_{1st}$$

其中 E_1st 为基频邻域能量，E_2nd 为二倍频邻域能量。

3. 谐波一致性误差

$$C_{h} = mean(|f_{2}(t) - 2 f_{1}(t)|)$$

标准动水噪声的 C_h 应较小。

#### 3.3.3 基频漂移特征

若一个分析窗完整覆盖单个鼓包，标准动水噪声的基频随时间往往呈“先升后降”趋势，可用二次曲线拟合：

$$f_{1}(t) ≈ a t^{2} + b t + c$$

但在部分窗或多鼓包窗中，不宜强制要求完整二次曲线拟合成立。此时推荐增加以下局部漂移特征：

$$ρ_{up} = N\{d f_{1} / d t > τ_{s}\} / N_{active}$$

$$ρ_{down} = N\{d f_{1} / d t < -τ_{s}\} / N_{active}$$

$$N_{turn} = N\{sign(d f_{1} / d t) 发生变化\}$$

推荐特征包括：

- 二次项系数 a：反映曲率；
- 频率跨度：

$$Δf_{span} = max(f_{1}) - min(f_{1})$$

- 归一化曲率：

$$C_{f} = mean(|d^{2} f_{1} / d t^{2}|)$$

- 上升帧占比 ρ_up、下降帧占比 ρ_down 和转折次数 N_turn：用于应对局部截断和多鼓包场景。

#### 3.3.4 结构有序性特征

1. 时频熵

$$H_{tf} = - Σ p_{ij} ln(p_{ij})$$

标准动水噪声虽然非平稳，但其能量相对集中在基频和二倍频脊线附近，因此时频熵不会无限大。

2. 脊线连续性

$$Ridge_{coh} = E_{ridge} / E_{total}$$

其中 E_ridge 为基频及二倍频脊线邻域能量总和。标准动水噪声的 Ridge_coh 一般较高。

3. 连通域数量与脊线数

对时频图中高能量区域进行二值化和连通域分析。标准动水噪声往往形成规则弧形或多段弧形结构，脊线条数和连通域形态相对稳定。

### 3.4 推荐特征组合

针对标准二倍频动水噪声的识别，建议优先使用以下特征：

1. 二倍频存在度 H2_ratio；
2. 谐波能量比 R_h；
3. 谐波一致性误差 C_h；
4. 包络对称性 S_env；
5. 脊线连续性 Ridge_coh；
6. 上升帧占比 ρ_up、下降帧占比 ρ_down 或转折次数 N_turn；
7. 多鼓包背景下的局部鼓包个数 N_bulge。

上述组合能够从包络、谐波、局部频率漂移和时频有序性四个层面共同刻画标准动水噪声。若单窗内未出现完整拱形轨迹，则应降低对二次项系数 a 的依赖，转而优先使用 H2_ratio、R_h、C_h、Ridge_coh、ρ_up、ρ_down 和 N_turn 等局部统计特征。

### 3.5 实验流程

1. 样本准备：整理高流速条件下无断丝、无外界干扰的标准动水噪声样本。
2. 事件切分：按鼓包事件或固定窗对信号切片，保证分析窗口长度一致；必要时在总分析窗内进一步采用短滑窗提取局部特征。
3. 包络分析：提取包络对称性、峰值位置比例、鼓包集中度和局部鼓包个数等特征。
4. 时频分析：计算 STFT 或 CWT，提取基频与二倍频脊线，并统计局部上升段、下降段及转折次数。
5. 谐波建模：统计 H2_ratio、R_h、C_h、ρ_up、ρ_down、N_turn 等指标，建立标准动水噪声模板分布。
6. 结构评价：计算脊线连续性、时频熵和图像连通域特征。
7. 判别门限：根据统计分布设定标准动水噪声识别门限，为第四章混合场景提供背景识别模块。

## 第四章 “二倍频动水噪声 + 断丝”与“二倍频动水噪声 + 冲击等干扰”混合信号特征提取

### 4.1 任务定义

本章研究对象为两类高流速混合信号：

- 二倍频动水噪声 + 断丝；
- 二倍频动水噪声 + 冲击等外界干扰。

本章目标是在已经识别出动水噪声背景的基础上，进一步区分附加瞬态是否为断丝。

### 4.2 研究思路

本章的关键思想是：标准动水噪声的谐波结构和鼓包包络属于“可解释的规则背景”，断丝或外界冲击则表现为附加的非规则瞬态。因此，应先建模并扣除可解释的动水噪声部分，再分析残差中的异常成分。

该任务的特征提取建议分为三层。

第一层，背景解释特征：判断该段信号中有多少能量可由标准动水噪声模板解释。

第二层，残差瞬态特征：在扣除谐波与鼓包结构后，分析是否存在短时宽带突发。

第三层，断丝细分特征：对残差瞬态进一步区分其是断丝还是外界冲击干扰。

在工程实现上，本章尤其不应假设一个分析窗只包含一个完整鼓包或一个完整附加瞬态。更稳妥的方案是在总窗内做短滑窗扫描，分别计算局部残差特征，然后对最大值、前 95% 分位数、异常子窗个数和连续异常时长进行统计。这类聚合特征对“半个断丝”“半个鼓包”以及“多鼓包叠加”场景更稳健。

### 4.3 推荐特征定义

#### 4.3.1 动水背景残差特征

在时频图上，基于第三章得到的主脊线 f_1(t) 和二倍频脊线 f_2(t)，构造谐波邻域掩膜 M_h(t, f)，据此定义：

1. 谐波可解释能量

$$E_{harm} = Σ (M_{h}(t, f) · P(t, f))$$

2. 残差能量

$$E_{res} = E_{total} - E_{harm}$$

其中

$$E_{total} = Σ P(t, f)$$

3. 非谐波残差能量占比

$$ρ_{res} = E_{res} / E_{total}$$

如果在标准动水噪声背景之外叠加了断丝或冲击，ρ_res 通常会上升。

4. 高频残差占比

$$R_{high,res} = E_{res,high} / E_{total}$$

其中 E_res,high 表示高频子带内的残差能量。断丝叠加时该特征通常更明显。

5. 异常子窗个数

设局部短窗中满足 ρ_res > τ_res 的子窗个数为 N_abn，则 N_abn 可反映总窗中附加异常瞬态出现的次数和分布范围。

#### 4.3.2 残差瞬态特征

1. 谱流量峰值

$$Flux(t_{i}) = Σ_{j} [P(t_{i}, f_{j}) - P(t_{i-1}, f_{j})]_{+}$$

其中 [z]_+ = max(z, 0)。定义峰值：

$$F_{peak} = max(Flux(t_{i}))$$

附加瞬态通常引起显著的谱流量峰值。

2. 残差谱质心突升

在残差时频能量上定义谱质心：

$$SC_{res}(t) = (Σ (f · P_{res}(t, f))) / (Σ P_{res}(t, f))$$

进一步定义其局部峰值或最大一阶差分：

$$ΔSC = max(d SC_{res} / d t)$$

3. 局部时频熵突增

在短滑窗内计算残差时频熵，取最大值 H_tf,res,max。断丝叠加通常会造成局部时频离散度上升。

#### 4.3.3 断丝与冲击干扰细分特征

由于“动水噪声 + 断丝”和“动水噪声 + 外界冲击”都可能表现为附加瞬态，因此需要进一步提取能体现断丝物理机理的特征。

1. 高频低频残差能量比衰减斜率

$$R_{res,hl}(t) = E_{res,high}(t) / E_{res,low}(t)$$

对其随时间拟合斜率 k_res,hl。断丝通常具有更稳定、更明显的高频快速衰减。

2. 残差谱质心衰减斜率

对 SC_res(t) 进行线性拟合，得到斜率 k_res,sc。断丝一般表现为更显著的负斜率。

3. 残差 TKEO 峰值比

在残差信号 x_res[n] 上计算：

$$Ψ_{res}[n] = x_{res}[n]^{2} - x_{res}[n-1] · x_{res}[n+1]$$

再定义：

$$R_{res,tkeo} = max(Ψ_{res}[n]) / mean(Ψ_{res}[n])$$

4. 残差局部峭度

在高频残差子带上计算滑动窗峭度 K_res，取最大值 K_res,max。

5. 残差包络不对称性

对残差信号计算包络 e_res(t)，再求：

$$S_{res,env} = corr(e_{res}(t), e_{res}^{rev}(t))$$

断丝残差更可能表现为非对称衰减，而部分外界冲击可能更接近尖峰后快速归零。

#### 4.3.4 小波与图像特征

在小波域和时频图像域，推荐以下补充特征：

- 高频小波包能量突发指数；
- 高频残差子带峭度；
- 小波熵；
- 高能量连通域个数；
- 主连通域长宽比；
- 主脊线弯曲度和连续性变化量。

这些特征适合作为辅助判别特征，特别适用于对复杂边界样本进行补充分析。

### 4.4 推荐特征组合

针对混合信号识别，建议采用“背景残差 + 断丝细分”的组合策略。

第一组，用于检测是否存在附加异常瞬态：

1. 非谐波残差能量占比 ρ_res；
2. 高频残差占比 R_high,res；
3. 谱流量峰值 F_peak；
4. 局部残差时频熵峰值 H_tf,res,max；
5. 异常子窗个数 N_abn。

第二组，用于区分附加瞬态是断丝还是冲击干扰：

1. 残差谱质心衰减斜率 k_res,sc；
2. 残差高低频能量比衰减斜率 k_res,hl；
3. 残差 TKEO 峰值比 R_res,tkeo；
4. 残差局部峭度 K_res,max；
5. 残差包络对称性 S_res,env。

综合考虑可解释性与稳健性，建议优先保留以下 7 个核心特征：

1. ρ_res；
2. R_high,res；
3. F_peak；
4. N_abn；
5. k_res,sc；
6. k_res,hl；
7. R_res,tkeo。

### 4.5 实验流程

1. 样本准备：整理两类混合信号样本，即“动水噪声 + 断丝”和“动水噪声 + 冲击干扰”。
2. 背景识别：基于第三章特征先判断该样本是否包含标准二倍频动水噪声结构；若总窗较长，则先划分局部滑窗。
3. 谐波掩膜构建：提取基频和二倍频脊线，构造动水噪声掩膜。
4. 残差提取：计算 E_harm、E_res、ρ_res 和高频残差占比。
5. 瞬态检测：在残差域计算谱流量、局部时频熵、谱质心突升等指标，判断是否存在附加宽带瞬态，并对多个异常子窗进行统计聚合。
6. 类型细分：针对附加瞬态，计算残差衰减斜率、TKEO、峭度和包络不对称性等特征，区分断丝与外界冲击。
7. 分类验证：采用少量强特征进行 SVM 或 XGBoost 验证，并重点考察误报率和漏报率。

## 第五章 潜在问题与难点分析

### 5.1 样本真实性与代表性不足

真实高流速下“动水噪声 + 断丝”样本往往稀缺，且断丝叠加程度不一致，容易导致训练样本数量不足或分布偏斜。若大量依赖人工挑选的明显样本，模型可能只学习到“显著断丝”，对弱断丝不敏感。

### 5.2 类间差异小而类内差异大

“动水噪声 + 断丝”与“动水噪声 + 冲击干扰”都包含附加瞬态，二者的整体波形可能非常接近，但每一类内部又会因为幅值、叠加位置、工况差异而变化很大。这会使单一绝对特征的稳定性较差。

### 5.3 窗口截断与多事件混叠问题

工程数据常采用固定长度信号窗，而信号窗与真实事件边界往往并不对齐。因此，一个窗内可能只含半个断丝、半个鼓包，也可能同时含有多个鼓包噪声。此时，依赖完整事件形态的特征会明显失稳，例如标准动水噪声“基频先升后降”的完整拱形轨迹不一定出现，单次包络对称性也可能因截断而失真。为降低这一风险，推荐采用局部短窗特征、事件候选计数、百分位数聚合和异常连续时长等统计特征。

### 5.4 非目标因素带来的偏差

若不同类别样本来自不同传感器、不同增益设置、不同采样率或不同工况，分类器可能学习到的是采集条件差异，而不是断丝机理差异。因此必须统一采样率、预处理流程、切窗规则和归一化方式，并尽量让不同类别在非目标因素上的分布一致。

### 5.5 特征冗余与过拟合风险

时域、频域、时频域、小波域和图像域均可提取大量特征，但样本量有限时，多特征堆叠会显著增加过拟合风险。建议先大范围提取候选特征，再通过相关性分析、Fisher score、AUC 和交叉验证逐步压缩到少量强特征。

### 5.6 门限和模型的工况迁移问题

不同流速、不同背景噪声强度下，特征分布可能发生漂移。固定门限在一个工况下有效，并不保证在其他工况下仍然有效。因此应采用按工况分组验证或跨批次验证，优先保留相对特征、比值特征和结构特征。

### 5.7 断丝与外界冲击在机理上的相似性

如果外界冲击源与传感器耦合方式接近结构内传播路径，其响应可能非常接近断丝，导致仅依靠单通道单事件信号难以彻底区分。若条件允许，建议后续结合多传感器到时差、跨通道一致性或事件上下文信息进一步降低误报。

| 残差谱质心 SC_res(t) | $$SC_{res}(t) = (Σ (f · P_{res}(t, f))) / (Σ P_{res}(t, f))$$ | 描述异常残差的中心频率位置。 | 第四章 | 中 |
| 残差谱质心衰减斜率 k_res,sc | 由 $$SC_{res}(t)$$ 线性拟合得到 | 描述残差高频向低频迁移规律，断丝残差常更符合衰减型结构响应。 | 第四章 | 高 |
| 残差高低频能量比 R_res,hl(t) | $$R_{res,hl}(t) = E_{res,high}(t) / E_{res,low}(t)$$ | 描述残差高频分量相对低频分量的占比。 | 第四章 | 高 |
| 残差高低频能量比衰减斜率 k_res,hl | 由 $$R_{res,hl}(t)$$ 线性拟合得到 | 刻画异常残差高频衰减速度，是断丝与外界冲击区分的重要指标。 | 第四章 | 高 |
| 残差 TKEO 峰值比 R_res,tkeo | $$R_{res,tkeo} = max(Ψ_{res}[n]) / mean(Ψ_{res}[n])$$ | 描述异常残差的尖锐瞬态程度。 | 第四章 | 高 |
| 残差局部峭度 K_res,max | 高频残差子带滑窗峭度最大值 | 用于区分断丝残差与强外界冲击残差。 | 第四章 | 中 |
| 残差包络对称性 S_res,env | $$S_{res,env} = corr(e_{res}(t), e_{res}^{rev}(t))$$ | 描述残差包络是否呈非对称衰减。 | 第四章 | 中 |

## 附录A 原始数据预处理与特征计算输入规范

### A.1 数据与符号基本约定

本方案默认原始输入为单个样本的一维时域信号，采样率为：

$$f_{s} = 200000 \text{ Hz}$$

样本时长约为：

$$T_{sample} ≈ 0.02 \text{ s}$$

因此每个样本点数约为：

$$N_{sample} = f_{s} · T_{sample} ≈ 4000$$

若使用离散表示，记原始时域信号为 x_raw[n]，其中：

- n：离散采样点编号，范围为 0 到 N_sample - 1；
- t_n：第 n 个采样点对应的时间，定义为：

$$t_{n} = n / f_{s}$$

- Δt：采样时间间隔，定义为：

$$Δt = 1 / f_{s} = 5 \text{ μs}$$

### A.2 统一预处理流程

为了保证各特征具备可比性，建议对每个样本统一执行以下预处理步骤。

1. 去直流与去趋势
设原始信号为 x_raw[n]，先减去均值，再去除一次线性趋势，得到 x_0[n]。
这一处理适用于全部特征，是最基础的输入规范。

2. 主分析带带通滤波
对 x_0[n] 做零相位带通滤波，推荐主分析带为 5 kHz 到 60 kHz，得到：

$$x_{B}[n] = BP_{5-60k}(x_{0}[n])$$

推荐原因是：低于 5 kHz 的慢变趋势和机械低频扰动通常不是本任务重点；高于 60 kHz 的频段在现有任务定义中信息量有限，且更容易受噪声影响。
该信号 x_B[n] 建议作为以下特征的默认输入：

- 包络特征；
- TKEO 特征；
- 主时频图计算；
- 事件检测与主瞬态定位。

3. 子频带滤波
为计算高低频能量比、衰减速率和残差子带特征，建议额外构造以下频带信号。

低频带：

$$x_{L}[n] = BP_{5-15k}(x_{0}[n])$$

中频带：

$$x_{M}[n] = BP_{15-30k}(x_{0}[n])$$

断丝主高频带：

$$x_{H1}[n] = BP_{20-40k}(x_{0}[n])$$

高流速残差高频带：

$$x_{H2}[n] = BP_{20-60k}(x_{0}[n])$$

其中：

- x_L[n] 主要用于低频能量 E_low 的计算；
- x_H1[n] 主要用于低流速断丝场景的高频能量 E_high 计算；
- x_H2[n] 主要用于高流速混合场景下残差高频能量 E_res,high 计算；
- x_M[n] 可作为补充频带，用于扩展子带能量特征或波包特征。

4. 包络计算
对需要包络特征的输入信号 s[n] 计算解析信号，得到包络：

$$e[n] = |hilbert(s[n])|$$

在第二章中，通常取 s[n] = x_B[n]；在第四章残差分析中，通常取 s[n] = x_res[n]。

5. 局部窗与滑窗
由于一个总窗可能只包含半个断丝或多个鼓包，建议在总窗内部再使用局部滑窗计算特征。
推荐局部窗长度为 0.8 ms 到 2.0 ms，对应 160 到 400 个采样点。
若需要固定推荐值，可先取：

$$N_{loc} = 256$$

对应时长为：

$$T_{loc} = N_{loc} / f_{s} = 1.28 \text{ ms}$$

局部窗步长可取 64 点，即 0.32 ms。
对一个总窗中的多个局部结果，建议取最大值、均值、95% 分位数、异常子窗个数或连续异常时长。

6. STFT 推荐参数
对时频特征，建议采用 Hamming 窗 STFT，推荐参数如下：

- 窗长 N_win = 128 点；
- 步长 N_hop = 32 点；
- N_fft = 512；
- 频率范围仅保留 0 到 100 kHz 的单边谱。

这样时间分辨率约为 0.16 ms，频率分辨率约为：

$$Δf_{bin} = f_{s} / N_{fft} ≈ 390.625 \text{ Hz}$$

7. 幅值归一化原则
并不是所有特征都应采用同一种归一化。

- 对能量比、残差占比、熵、相关系数等相对特征，可直接使用滤波后的原始幅值；
- 对仅关注形状而不关心绝对幅值的特征，可在局部窗内用 RMS 归一化：

$$x_{norm}[n] = x[n] / RMS(x)$$

- 不建议在全部特征之前统一做峰值归一化，否则会损失反映真实能量变化的特征信息。

### A.3 各特征推荐输入信号汇总

| 特征类别 | 推荐输入信号 | 额外预处理 | 备注 |
| --- | --- | --- | --- |
| 包络峰值位置、上升下降时间比、前后能量比、包络对称性、包络偏度 | $$x_{B}[n]$$ | Hilbert 包络 | 第二章默认使用主分析带 |
| TKEO 峰值比 | $$x_{B}[n]$$ | 可先做 RMS 归一化 | 对尖锐瞬态较敏感 |
| 高频半衰期 | $$x_{H1}[n]$$ | Hilbert 包络 | 低流速断丝场景优先 |
| 高低频能量比及其斜率 | $$x_{L}[n]$$ 与 $$x_{H1}[n]$$ | STFT 或滑窗能量 | 第二章默认配置 |
| 标准动水噪声的谐波特征 | $$x_{B}[n]$$ | STFT、脊线提取 | 第三章默认使用主分析带 |
| 局部鼓包个数 | $$x_{B}[n]$$ | Hilbert 包络、阈值分割 | 适合多鼓包背景 |
| 残差能量、残差高频占比 | $$P(t,f)$$ 与 $$M_{h}(t,f)$$ | 谐波掩膜 | 第四章先在时频域计算 |

## 附录B 公式量的物理意义与可编程计算说明

### B.1 包络类特征

1. 包络 e[n]
对输入信号 s[n] 做 Hilbert 变换后取模，得到包络：

$$e[n] = |hilbert(s[n])|$$

其中：

- s[n]：当前特征使用的输入信号，通常为 x_B[n] 或 x_res[n]；
- e[n]：包络序列，长度与 s[n] 相同。

2. 峰值时刻 t_peak
先求包络最大值位置：

$$n_{peak} = argmax(e[n])$$

再换算为时间：

$$t_{peak} = n_{peak} / f_{s}$$

3. 局部窗长度 T
若当前特征在长度为 N 个采样点的局部窗内计算，则：

$$T = N / f_{s}$$

4. 上升时间 T_rise
设包络峰值为 e_peak = e[n_peak]。
在峰值左侧寻找最后一个满足 e[n] <= 0.1 e_peak 的采样点 n_10,left，则：

$$T_{rise} = (n_{peak} - n_{10,left}) / f_{s}$$

5. 下降时间 T_decay
在峰值右侧寻找第一个满足 e[n] <= 0.1 e_peak 的采样点 n_10,right，则：

$$T_{decay} = (n_{10,right} - n_{peak}) / f_{s}$$

若右侧在当前局部窗内未衰减到 10%，则可记为当前窗末端时长，或将该窗标记为截断窗，后续只参与最大值或分位数聚合。

6. 前后能量 E_before 与 E_after
建议使用包络平方积分：

$$E_{before} = Σ_{n = 0}^{n_{peak}} e[n]^{2} · Δt$$

$$E_{after} = Σ_{n = n_{peak}}^{N - 1} e[n]^{2} · Δt$$

若采用离散和而不乘 Δt，也可以，只要所有样本保持一致。

7. 反转包络 e_rev[n]
定义为：

$$e^{rev}[n] = e[N - 1 - n]$$

8. 包络对称性 corr(·)
建议采用皮尔逊相关系数。对两个等长序列 a[n] 和 b[n]，其相关系数为：

$$corr(a,b) = cov(a,b) / (σ_{a} σ_{b})$$

9. 包络均值 μ_e 与标准差 σ_e
定义为：

$$μ_{e} = mean(e[n])$$

$$σ_{e} = std(e[n])$$

### B.2 STFT 与功率谱量

1. STFT 复谱 S(t_i, f_j)
对输入信号做 STFT 后得到的复数频谱，其中：

- t_i：第 i 个时间帧中心时刻；
- f_j：第 j 个频率 bin 对应的中心频率；
- j 的频率映射为：

$$f_{j} = j · f_{s} / N_{fft}$$

仅保留单边频率时，j 从 0 到 N_fft / 2。

2. 功率谱 P(t_i, f_j)
定义为：

$$P(t_{i}, f_{j}) = |S(t_{i}, f_{j})|^{2}$$

这是后续谱质心、能量比、熵、谱流量等特征的基础。

3. 活跃时间帧 N_active
建议先计算每个时间帧在主分析带 5 kHz 到 60 kHz 内的总能量 E_frame(i)。
若 E_frame(i) 高于全样本该量中位数的 1.5 倍，或高于最大值的 10%，则记为活跃帧。
N_active 即满足条件的帧数。

### B.3 频率演化与能量比特征

1. 谱质心 SC(t_i)
在每个时间帧上，使用目标频带内的功率谱加权求平均：

$$SC(t_{i}) = (Σ_{j} (f_{j} · P(t_{i}, f_{j}))) / (Σ_{j} P(t_{i}, f_{j}))$$

求和范围建议限制在 5 kHz 到 60 kHz 主分析带内。
SC(t_i) 的单位是 Hz。

2. 谱质心斜率 k_sc
对活跃时间帧上的 SC(t_i) 与 t_i 做最小二乘直线拟合：

$$SC(t_{i}) ≈ k_{sc} t_{i} + b_{sc}$$

其中 k_sc 即斜率。若 k_sc < 0，表示谱质心整体随时间下降。

3. 高频能量 E_high(t_i) 与低频能量 E_low(t_i)
第二章推荐使用：

- 低频带：5 kHz 到 15 kHz；
- 高频带：20 kHz 到 40 kHz。

则：

$$E_{low}(t_{i}) = Σ_{f_{j} ∈ [5,15]kHz} P(t_{i}, f_{j})$$

$$E_{high}(t_{i}) = Σ_{f_{j} ∈ [20,40]kHz} P(t_{i}, f_{j})$$

4. 高频低频能量比 R_hl(t_i)
定义为：

$$R_{hl}(t_{i}) = E_{high}(t_{i}) / E_{low}(t_{i})$$

为避免分母接近 0，编程实现时建议写成：

$$R_{hl}(t_{i}) = E_{high}(t_{i}) / (E_{low}(t_{i}) + ε)$$

其中 ε 可取一个很小正数，如 10^-12。

5. 高频低频能量比斜率 k_hl
对活跃帧上的 R_hl(t_i) 做最小二乘直线拟合得到。

### B.4 熵与谱流量

1. 归一化时频概率 p_ij
定义为：

$$p_{ij} = P(t_{i}, f_{j}) / (Σ_{i,j} P(t_{i}, f_{j}))$$

若计算的是某个局部窗或残差时频图，则求和范围限制在对应区域内。

2. 时频熵 H_tf
定义为：

$$H_{tf} = - Σ_{i,j} p_{ij} ln(p_{ij})$$

编程时对 p_ij = 0 的项可直接跳过，或采用 p_ij + ε 形式。

3. 谱流量 Flux(t_i)
用相邻时间帧功率谱的正向变化量定义：

$$Flux(t_{i}) = Σ_{j} max(P(t_{i}, f_{j}) - P(t_{i-1}, f_{j}), 0)$$

F_peak 则取所有活跃帧中的最大谱流量。

### B.5 TKEO、峭度与半衰期

1. TKEO Ψ[n]
定义为：

$$Ψ[n] = x[n]^{2} - x[n-1] x[n+1]$$

其中 x[n] 为当前输入信号，通常为 x_B[n]、x_res[n] 或其局部窗。
边界点 n = 0 和 n = N - 1 可不计算，或直接复制相邻值。

2. TKEO 峰值比
定义为：

$$R_{tkeo} = max(Ψ[n]) / mean(Ψ[n])$$

残差 TKEO 特征 R_res,tkeo 的定义完全相同，只是输入换成 x_res[n]。

3. 峭度 K
对长度为 N 的序列 x[n]，均值为 μ，标准差为 σ，则：

$$K = ((1 / N) Σ (x[n] - μ)^{4}) / σ^{4}$$

若在滑动窗内计算，则 K_res,max 为所有滑动窗峭度的最大值。

4. 高频半衰期 T_half,high
先对高频带信号 x_H1[n] 计算包络 e_H[n]，设峰值点为 n_peak。
从峰值之后寻找第一个满足：

$$e_{H}[n] <= 0.5 e_{H}[n_{peak}]$$

的采样点 n_half，则：

$$T_{half,high} = (n_{half} - n_{peak}) / f_{s}$$

### B.6 标准动水噪声的脊线与谐波量

1. 主脊线 f_1(t_i)
对每个活跃时间帧，在 5 kHz 到 30 kHz 范围内寻找功率谱局部最大峰，选能量最高者作为基频候选。其频率即 f_1(t_i)。

2. 次脊线 f_2(t_i)
在 10 kHz 到 60 kHz 范围内寻找局部峰，选与 2f_1(t_i) 最接近且能量较高的峰作为二倍频候选。

3. 二倍频存在度 H2_ratio
若某帧满足：

$$|f_{2}(t_{i}) - 2 f_{1}(t_{i})| < Δf_{tol}$$

则认为该帧存在有效二倍频。
Δf_tol 建议取 1 kHz，或 2 到 3 个频率 bin。
H2_ratio 等于满足条件的活跃帧数除以 N_active。

4. 谐波能量 E_1st 与 E_2nd
在 f_1(t_i) 和 f_2(t_i) 周围各取一个窄带邻域，推荐半带宽为 1 kHz：

- 基频能量 E_1st：所有活跃帧内 f_1(t_i) ± 1 kHz 邻域功率之和；
- 二倍频能量 E_2nd：所有活跃帧内 f_2(t_i) ± 1 kHz 邻域功率之和。

则：

$$R_{h} = E_{2nd} / E_{1st}$$

5. 谐波一致性误差 C_h
定义为活跃帧上 |f_2(t_i) - 2f_1(t_i)| 的平均值。

6. 上升帧占比 ρ_up 与下降帧占比 ρ_down
对相邻活跃帧做一阶差分：

$$d f_{1} / d t ≈ (f_{1}(t_{i}) - f_{1}(t_{i-1})) / (t_{i} - t_{i-1})$$

若该差分大于阈值 τ_s，则记为上升帧；若小于 -τ_s，则记为下降帧。
τ_s 建议取 1 kHz/ms 到 3 kHz/ms 的量级，根据样本情况调节。

7. 转折次数 N_turn
统计 sign(df_1 / dt) 在活跃帧序列中发生正负切换的次数。
若一个窗内包含多个鼓包，N_turn 往往会增大。

8. 脊线连续性 Ridge_coh
先构造谐波脊线掩膜 M_h(t_i, f_j)。
对每个活跃帧，在 f_1(t_i) 与 f_2(t_i) 附近各取 ±1 kHz 邻域，掩膜值为 1，其余为 0。
则：

$$E_{ridge} = Σ M_{h}(t_{i}, f_{j}) P(t_{i}, f_{j})$$

$$E_{total} = Σ P(t_{i}, f_{j})$$

$$Ridge_{coh} = E_{ridge} / E_{total}$$

### B.7 残差与混合场景特征

1. 时频残差功率谱 P_res(t_i, f_j)
在构造了谐波掩膜 M_h 后，定义：

$$P_{res}(t_{i}, f_{j}) = (1 - M_{h}(t_{i}, f_{j})) P(t_{i}, f_{j})$$

2. 谐波可解释能量与残差能量
定义为：

$$E_{harm} = Σ M_{h}(t_{i}, f_{j}) P(t_{i}, f_{j})$$

$$E_{res} = Σ P_{res}(t_{i}, f_{j})$$

$$E_{total} = Σ P(t_{i}, f_{j})$$

$$ρ_{res} = E_{res} / E_{total}$$

3. 高频残差能量 E_res,high
第四章推荐高频残差带取 20 kHz 到 60 kHz，则：

$$E_{res,high}(t_{i}) = Σ_{f_{j} ∈ [20,60]kHz} P_{res}(t_{i}, f_{j})$$

对应总窗上的高频残差占比为：

$$R_{high,res} = (Σ E_{res,high}(t_{i})) / E_{total}$$

4. 异常子窗个数 N_abn
先在总窗内按局部滑窗计算 ρ_res。若某局部窗满足：

$$ρ_{res}^{(m)} > τ_{res}$$

则该局部窗记为异常窗。
τ_res 建议在纯标准动水噪声样本上统计分布后取 95% 分位点或均值加 3 倍标准差。

5. 残差谱质心 SC_res(t_i)
定义为：

$$SC_{res}(t_{i}) = (Σ_{j} (f_{j} · P_{res}(t_{i}, f_{j}))) / (Σ_{j} P_{res}(t_{i}, f_{j}))$$

其斜率 k_res,sc 同样通过对活跃残差帧做线性拟合得到。

6. 残差高低频能量比 R_res,hl(t_i)
建议取：

- 低频残差带：5 kHz 到 15 kHz；
- 高频残差带：20 kHz 到 60 kHz。

则：

$$R_{res,hl}(t_{i}) = E_{res,high}(t_{i}) / (E_{res,low}(t_{i}) + ε)$$

其中 E_res,low(t_i) 为残差低频带能量。

7. 时域残差信号 x_res[n]
若需要计算残差包络或残差 TKEO，建议从 STFT 残差 P_res 对应的复谱残差中做逆 STFT 重构，得到 x_res[n]。
若暂不做逆变换，也可直接在时频域使用残差特征完成识别；但对 S_res,env 和 R_res,tkeo，推荐使用重构后的 x_res[n]。

### B.8 编程实现时的建议顺序

为便于后续直接编程实现，建议按照以下顺序组织特征计算函数。

1. 输入原始单窗信号 x_raw[n] 与采样率 fs。
2. 执行去均值、去趋势、主带通和子带通滤波，得到 x_B[n]、x_L[n]、x_H1[n]、x_H2[n]。
3. 在 x_B[n] 上做事件定位或局部滑窗划分。
4. 计算第二章特征时，默认输入为 x_B[n]、x_L[n]、x_H1[n] 及其 STFT。
5. 计算第三章特征时，默认输入为 x_B[n] 的 STFT 与包络。
6. 计算第四章特征时，先从 x_B[n] 的 STFT 中提取 f_1、f_2 和谐波掩膜，再得到 P_res 和 x_res[n]。
7. 对局部窗结果做聚合，形成单样本最终特征向量。

## 第六章 小结

本研究提出了一套面向复杂信号环境的断丝识别方案，其核心不是直接对全部场景进行一步分类，而是按照“低流速本征特征提取 -> 高流速标准动水噪声建模 -> 高流速混合信号残差识别”的路线逐层推进。

第二章聚焦低流速场景，推荐以包络不对称性、上升下降时间比、谱质心衰减斜率、高低频能量比衰减斜率、TKEO 峰值比和高频子带峭度为核心特征，用于建立断丝的本征表达并抑制平稳噪声和冲击干扰。该章同时强调，对只截取到半个断丝的样本，应使用主瞬态定位和局部特征聚合，而不是仅依赖整窗特征。

第三章聚焦标准二倍频动水噪声，推荐以包络对称性、二倍频存在度、谐波能量比、谐波一致性误差、局部上升下降帧占比、基频曲率和脊线连续性为核心特征，用于在高流速背景中识别并排除标准动水噪声。这里尤其强调，识别依据不应建立在单窗必须出现完整“先升后降”的前提上。

第四章聚焦混合场景，推荐以非谐波残差能量占比、高频残差占比、谱流量峰值、异常子窗个数、残差谱质心衰减斜率、残差高低频能量比衰减斜率和残差 TKEO 峰值比为核心特征，用于从“动水噪声 + 断丝”和“动水噪声 + 外界冲击”两类混合信号中识别出断丝。对于“半个断丝”或“多鼓包背景”情形，建议在总窗内部使用短滑窗计算这些指标，并采用峰值、分位数和异常子窗计数进行聚合。

从工程实现角度，建议优先建立少量强特征的分层判别系统，并通过跨批次、跨工况验证逐步完善。在样本量有限的阶段，应优先保证样本来源的一致性和特征定义的物理可解释性，而非追求复杂模型。后续若数据条件允许，可在该特征体系基础上进一步扩展为多传感器联合识别和在线报警系统。
