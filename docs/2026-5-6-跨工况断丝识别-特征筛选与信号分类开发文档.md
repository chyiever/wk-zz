## 3. 输入约定

### 3.1 输入文件

输入为一份特征 CSV，每行对应一个样本。当前代码默认支持以下元信息列：

- `label`
- `sample_name`
- `sample_rate`
- `folder_name`

如果 CSV 中已经包含 `split` 列，代码优先使用该列；如果没有，则从 `folder_name` 或 `sample_name` 推断。

### 3.2 标签规范

标签最终会被统一为二值：

- `1`：断丝类
- `0`：流噪声类

代码同时兼容数值、布尔值和常见字符串编码。

### 3.3 工况与分组推断

代码会从 `folder_name` 中推断两个字段：

- `split`
  - `train`
  - `test`
- `base_domain`
  - `F130`
  - `F130A`
  - `F130C`

例如：

- `F130_tr` -> `base_domain=F130`, `split=train`
- `BK14_f130_te` -> `base_domain=F130`, `split=test`

这样可以同时支持：

- 原始噪声子集
- 原始断丝混合子集
- 训练 / 测试分离后的同域评估

## 4. 实现的实验协议

### 4.1 7 组训练工况

`split_protocol.py` 中固定了 7 组训练域组合：

1. `F130`
2. `F130A`
3. `F130C`
4. `F130 + F130A`
5. `F130 + F130C`
6. `F130A + F130C`
7. `F130 + F130A + F130C`

每组实验都对以下 3 个测试域分别评估：

- `F130`
- `F130A`
- `F130C`

### 4.2 训练 / 测试划分口径

训练阶段只使用：

- `split=train`
- 且 `base_domain` 属于当前实验的训练域集合

测试阶段只使用：

- `split=test`
- 且 `base_domain` 等于待评估域

这保证了特征筛选、模型选择和阈值选择都只在训练域内部完成。

## 5. 特征筛选实现

### 5.1 阶段 A：过滤式预筛选

对应实现文件：`src/fea_sel_clasf/feature_filter.py`

阶段 A 在训练域内部完成，主要步骤如下：

1. 提取数值特征矩阵
2. 统一做中位数填补
3. 计算每个特征的：
   - 缺失率
   - 方差
   - 与标签的 Pearson 相关系数绝对值
   - `mutual_info_classif`
   - 跨工况稳定性分数
4. 删除：
   - 缺失率超过阈值的特征
   - 方差低于阈值的特征
5. 计算综合分数：
   - `Score = 0.7 * MI_norm + 0.3 * Stability`
6. 按综合分数排序后，做高相关冗余剪枝
7. 取 Top-K 作为阶段 A 候选特征集

### 5.2 稳定性定义

代码里将稳定性定义为训练域之间分布差异的反量化结果：

- 对每个特征，计算不同训练域之间的 Wasserstein 距离
- 用池化标准差做归一化
- 再转换成 `1 / (1 + normalized_distance)` 形式

这样做的含义是：

- 各域分布越接近，稳定性越高
- 各域分布差异越大，稳定性越低

### 5.3 高相关剪枝

当特征之间的 Pearson 相关系数绝对值超过阈值时，代码采用贪心方式保留排在前面的特征，后面的冗余特征会被剔除。

这样可以避免：

- 重复特征挤占 Top-K 配额
- RFECV 在高度共线的特征上浪费搜索成本

## 6. 包裹式精筛实现

对应实现文件：`src/fea_sel_clasf/feature_wrapper.py`

阶段 B 在阶段 A 候选集上执行 `RFECV`，核心配置为：

- 基学习器：`LinearSVC(class_weight='balanced')`
- 预处理：`SimpleImputer(median) + StandardScaler`
- 交叉验证：`StratifiedKFold`
- 评分：`f1`

输出内容包括：

- 最终保留特征列表
- 每个候选特征的 `rfecv_support`
- 每个候选特征的 `rfecv_ranking`

最终特征写入：

- `selected_features.csv`

## 7. 分类器搜索与阈值固定

### 7.1 候选模型池

对应实现文件：`src/fea_sel_clasf/model_zoo.py`

当前候选池包括：

- `LogisticRegression(class_weight='balanced')`
- `SVC(kernel='rbf', class_weight='balanced', probability=True)`
- `RandomForestClassifier(class_weight='balanced_subsample')`
- `XGBoost`：如果环境中可用则自动加入，不可用则跳过

### 7.2 模型选择规则

对每个候选模型及其参数组合，代码在训练域内部做交叉验证，并按以下顺序选择最优：

1. `Recall_pos` 均值最大
2. `Balanced_Accuracy` 均值最大
3. `Recall_pos` 标准差更小
4. `Balanced_Accuracy` 标准差更小

这与可执行方案中的优先级一致。

### 7.3 阈值选择

对应实现文件：`src/fea_sel_clasf/thresholding.py`

阈值不是固定使用 `0.5`，而是基于训练域上的 OOF 概率选择：

- 在满足 `Recall_pos >= target_recall` 的阈值集合中
- 选择 `FPR` 最小的阈值

如果没有任何阈值满足目标召回，则回退到：

- 选择 OOF 上 `Balanced_Accuracy` 最大的阈值

阈值固定写入：

- `threshold.json`

## 9. 复现入口

当前实现的主入口是：

```python
from src.fea_sel_clasf.runner import run_cross_condition_experiments
```

调用示例：

```python
run_cross_condition_experiments(
    input_csv="path/to/feature_table.csv",
    output_root="outputs/model_test_cross_condition_260506",
    random_state=42,
```
